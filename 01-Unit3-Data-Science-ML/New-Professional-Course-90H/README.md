# יחידה 3 — מסלול הוראה חדש, עצמאי
**כיתה י׳ | תכנון 90 שעות | גרסה חדשה בתהליך פיתוח**

זהו מסלול חדש, נפרד לחלוטין מ־`Lesson-Plans-2026-2027/Professional-Course-90H`. הוא יפותח מתוך תכנית הלימודים, מצגות ההשתלמות ותרגולי המקור שב־`01-Unit3-Data-Science-ML`. אין למחוק חומרי מקור לפני מיפוי וביקורת. התיקייה החדשה היא מקום העבודה העיקרי לפיתוח המסלול החדש; היא **אינה** טענה שכל 90 השעות כבר מוכנות.

## ארבעה תוצרים בלבד לכל מפגש
1. `01-Teacher-Guide.md`: הוראה מדורגת ומפורטת; חשיבות ל־AI; נוסחאות, חישוב ידני, גרפים, Python; קישורי הרחבה מקצועיים והנחיות למורה.
2. `02-NotebookLM-Subprompts.md`: תתי־פרומפטים בני 8–10 שקפים להפקת מצגות משנה שאפשר לאחד מאוחר יותר; ללא חשיפת תשובות התרגול.
3. `03-Student-Practice.md`: דף עבודה הדרגתי עם קוד `?` להשלמה, סיפור דומה אך שונה מההדגמה וממצגות ההשתלמות.
4. `04-Teacher-Solution.md`: פתרון מורה מלא ומתועד, חישוב ידני, קוד, פלט, פירוש ושגיאות שכיחות.

## מדיניות
- עברית ברורה בגובה העיניים, שמות עבריים מתחלפים; ללא שימוש בשם דודו.
- בחירה של נושאים לפי תכנית הלימודים והתכנים הקיימים, ולא לפי מספור שיעורי ההשתלמות.
- אין תיקיות הוראה מקבילות בתוך המסלול החדש.
- סימני `?` ו־`???` בתרגולים הם השלמות מכוונות, לא שגיאות. מפתחות תשובות שמורים למורה בלבד.
- 8–10 שקפים **לכל מצגת משנה**, מספר חלקים לפי עומק הנושא. ללא הגבלה מלאכותית של 10 שקפים לנושא שלם.
- כל ערכה עוברת בדיקת דיוק מדעי, מתמטי, לשוני, התאמת המעבדה והרצה; מצגת NotebookLM דורשת גם הגהה חזותית.
- אין למזג אוטומטית תכנים מן המסלול הישן ואין למחוק תיקיות ישנות עד שמוודאים שהמסלול החדש מכסה את כל הנדרש.
