## משימה 1 — מבנה
```python
import pandas as pd
df = pd.DataFrame({
    "name":["דניאל","יובל","שחר","הדר"],
    "hours":[3,5,2,4],
    "score":[72,88,65,91]
})
print(df.shape)
print(df.head(2))
```
הצורה היא `(4,3)`: ארבע שורות ו־3 עמודות כולל שם. `head(2)` מציגה שתי שורות ראשונות בלבד ואינה מוחקת נתונים.

## משימה 2 — Series וטבלה
```python
scores_series = df["score"]
scores_table = df[["score"]]
print(scores_series.shape)   # (4,)
print(scores_table.shape)    # (4, 1)
```
הסבירו שפסיק ב־`(4,)` אינו עמודה נוספת: זו צורה חד־ממדית.

## משימה 3 — בחירה
```python
features = df[["hours", "score"]]
print(features.shape)   # (4, 2)
```
הבחירה משנה את מספר העמודות *בתוצאה* ולא מוחקת שורות או משנה את `df` המקורית. לצורך **חיזוי score לפי hours** אין להזין את `score` כמאפיין! כאן הבחירה נועדה ללמד תחביר בלבד.

## משימה 4 — מסכה
```python
mask = df["score"] >= 85
print(mask.tolist())
selected = df[mask]
print(selected[["name", "score"]])
```
מסכה `[False, True, False, True]`. נבחרים **יובל 88, הדר 91**, שתי תצפיות. הדגישו `>=` כולל את 85, ואילו `>` לא. בחירת שתי עמודות אינה מסננת שורות.

## משימה 5 — חישוב ידני
`72+88+65+91=316`, לכן ממוצע `316/4=79` נקודות. מינימום `65`, מקסימום `91`. הפלט של `mean()` עשוי להיות `79.0`. אין לקבוע סיבתיות בין שעות לציון בגלל ארבע דוגמאות.

## משימה 6 — AI
`hours` הוא מאפיין אפשרי, `score` יעד; `name` מזהה תלמיד ולא מדד מספרי של יכולת. בדקו איכות נתונים, משמעות שדות, חסרים, הוגנות, התאמה לסוג השאלה ומדגם מספק; בהמשך חלוקה ל־Train/Test. אין עדיין הצדקה ללמד מודל.

## כרטיס יציאה
`df[["hours","score"]]`; סוגריים כפולים = רשימת שמות עמודות. `head(2)` מציגה תחילת טבלה בלבד. סינון `df[df["score"]>=85]` בוחר **שורות** לפי תנאי.
