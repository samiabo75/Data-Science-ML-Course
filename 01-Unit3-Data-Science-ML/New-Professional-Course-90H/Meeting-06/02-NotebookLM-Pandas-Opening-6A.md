## הוראות קבועות להפקה
צור מצגות מקצועיות לכיתה י׳ בעברית טבעית, נכונה ונוחה לקריאה מימין לשמאל. יחס 16:9, רקע לבן/בהיר, כותרות קצרות בגופן גדול; קוד באנגלית בכיוון LTR עם גופן מונוספייס גדול וניגודיות גבוהה. **אסור להציב חץ או תווית על גבי אותיות הקוד, סוגריים, סימני פיסוק או פלט.** אין קווים מחוברים לתווים בקוד; את הפירוק יש להציג **מתחת לקוד**, בטבלת שתי עמודות (רכיב | משמעות) או בארבעה כרטיסים נקיים. שקף = רעיון אחד, עד 2–3 הערות שוליים קצרות, ללא תמונת מדע בדיוני דקורטיבית. בחר המחשה אמיתית של טבלת 4×3 על פני איור עתידני. תן למורה הערות הוראה מפורטות, אך בשקפים עצמם הימנע מפסקאות עמוסות.
מותר להשתמש **רק** בדוגמת המורה המוגדרת כאן להדגמות ידניות; במחברות התלמיד משתמשים ב־Penguins ממאגר הקורס — אין להעתיק ממנו תוצאות ותשובות למצגת.
הוראה מחייבת לכל פקודה חדשה: שאלה מן העולם המוכר → פעולת ידע קודם → מגבלה של הכלי הקודם → צורך חדש → תחביר מפורק → קוד מלא → פלט נכון → פירוש התוצאה → שאלה שבה התלמיד מנבא שינוי.
**אין להציג את Pandas כאילו היא מחליפה את NumPy או מחייבת להמיר תחילה למערך NumPy.** NumPy מיועדת במיוחד לחישובים על מערכים רב־ממדיים; Pandas נוחה לעבודה טבלאית עם עמודות בעלות שמות, טיפוסים שונים, אינדקסים וחסרים. Pandas משתמשת גם ב־NumPy במקרים רבים, והשתיים משלימות זו את זו.
לעבוד עם דוגמה עקבית לכל אורך שני החלקים:
```python
import numpy as np
import pandas as pd

X = np.array([[2, 65],
              [4, 82],
              [3, 74],
              [5, 91]])

data = {
    "name": ["נועה", "איתי", "שיר", "עומר"],
    "hours": [2, 4, 3, 5],
    "score": [65, 82, 74, 91]
}
df = pd.DataFrame(data)
```
**פלט DataFrame מדויק:**
```text
   name  hours  score
0  נועה      2     65
1  איתי      4     82
2   שיר      3     74
3  עומר      5     91
```
הטבלה ממחישה ארבע רשומות ושלושה שדות; ספריית Pandas **אינה** יוצרת באופן אוטומטי את שמות התלמידים מתוך המטריצה. הוספתם היא נתון חדש שסופק במילון.

## פרומפט עצמאי ל־NotebookLM: 6א־1 — למה בכלל Pandas? (9 שקפים)
**מקורות להעלאה:** מצגת 'ממערכים ל־DataFrame' **כדוגמה שיש לתקן** (לא מקור לתחביר חזותי), מצגת ההשתלמות `2.1 Python for DS`, מדריך המורה של מפגש 6; אפשר לצרף מצגת שיעור 5 של NumPy אם זמינה. אין לצרף פתרונות.

**תפקידך:** מורה מומחה למדעי הנתונים, המתכנן למידה מבוססת ידע קודם. אל תתחיל בקוד חדש. המטרה: שהתלמיד יבין *למה* אנו צריכים Pandas, איך היא קשורה ל־NumPy ומהי ספריית Python, ויזהה שורות, עמודות ושמות שדות לפני כתיבת פקודות.

1. **שער ממוקד:** ״משיעור 5 לשיעור 6: ממערכי מספרים לטבלאות בעלות משמעות״. הצג NumPy → שאלה על שמות שדות → Pandas. משפט קצר: נלמד לקרוא ולחקור נתונים אמיתיים לפני שימוש בהם ב־AI.
2. **מהי ספרייה ב־Python?** השווה ל״ארגז כלים״: במקום לכתוב הכול בעצמנו, משתמשים בפעולות מוכנות. הבדל בין Python כשפה, NumPy כספריית מערכים מספריים, Pandas כספריית עבודה טבלאית. שלוש קוביות גרפיות נקיות, ללא מחשבים עתידניים.
3. **מהי Pandas ומדוע משתמשים בה?** טבלה עם שורות תצפית ועמודות מאפיין; שמות עמודות, סוגי נתונים שונים, אפשרות לטעון CSV, לחקור חסרים ולסנן. לא להציג `groupby` או `fillna` עדיין. המחשה של טבלת התלמידים המלאה.
4. **חזרה לשיעור 5 — מטריצת NumPy:** הצג את X המדויק בעל ארבע שורות ושתי עמודות. הדגם `X.shape` → `(4, 2)` ואת `X[1, 1]` → `82`, עם סימון שורה 1 ועמודה 1. חשוב לציין: אינדקס 0 מתחיל את הספירה.
5. **מה חסר במטריצה?** הצג את אותו X ושאל: האם העמודה הראשונה היא שעות תרגול או גיל? המחשב יודע מספר, אך המשמעות תלויה בהגדרת המאפיין. הוסף *כותרות* `hours` ו־`score` כתיוג חזותי בלבד; לא לשנות את X ולא לטעון שמספרים חסרי משמעות.
6. **מה NumPy עושה היטב?** על X הצג `X[:, 1]` ואת ארבעת הציונים; כרטיס יתרונות: פעולות מספריות, ממדים ומרחקים. לידו השאלה: איך בוחרים עמודת `score` לפי שם ולא לפי מספר? אין לטעון שהדבר בלתי אפשרי ב־NumPy, אלא שהוא פחות ישיר במערך ללא שמות שדות.
7. **השוואה ישירה והוגנת:** משמאל NumPy X עם המספרים 2/65,4/82,3/74;5/91; מימין טבלה עם השדות `hours`, `score` **ואותם ערכים בדיוק**. השורה הרביעית חייבת להיות עומר 5/91 רק לאחר הוספת עמודת name בנפרד. הבלט שם עמודה ומיקום עמודה כמנגנוני בחירה, בלי קוד Pandas חדש.
8. **שאלה מחקרית וכיוון ל־AI:** האם יותר שעות תרגול קשורות לציון גבוה יותר? המידע בטבלה מאפשר לשאול, אך ארבע רשומות לא מוכיחות סיבתיות. תרשים פיזור קטן ומדויק עם נקודות (2,65),(4,82),(3,74),(5,91), צירים ויחידות, או טבלה בלבד אם התרשים עמוס.
9. **כרטיס יציאה ומשפט מעבר:** השלימו: מהי ספרייה, במה NumPy טובה, במה Pandas עוזרת ומהי תצפית. סיום: ״כדי לעבוד עם טבלה בעלת שמות נלמד כעת ליצור DataFrame״.

**מבחן הצלחה:** לאחר תשעת השקפים תלמיד כיתה י׳ מסוגל להסביר מהי ספרייה, להבחין בין NumPy ל־Pandas ולהסביר למה שמות עמודות שימושיים, בלי שראה עדיין קוד מסובך.

## פרומפט עצמאי ל־NotebookLM: 6א־2 — יוצרים DataFrame וקוראים CSV (10 שקפים)
**מקורות להעלאה:** מצגת ההשתלמות 2.1, מחברת `Pandas_01` ומדריך המורה. דוגמת הקוד נשענת על 6א־1. אין לצרף פתרון של חוברת תלמיד Penguins.
**מטרה מדידה:** התלמיד יוכל להסביר `import pandas as pd`, לבנות `pd.DataFrame(data)`, לזהות `df.shape` ולטעון CSV ל־DataFrame. כל פקודה נלמדת על נתוני המורה, ולא על פתרון התרגול.

1. **משפט פתיחה:** ״מה צריך כדי להפוך רשימות עם שמות לטבלה?״ הצג שוב את ארבע הרשומות של יעל ואת שלושת השדות `name,hours,score`, בלי קוד.
2. **מה פירוש `import pandas as pd`?** כתוב שורת קוד אחת **גדולה וללא חצים עליה**. מתחת: `import` = טעינת ספרייה; `pandas` = שם ספרייה; `as` = הגדרת שם מקוצר; `pd` = הכינוי. אל תציג פלט מומצא — פקודת import רגילה אינה מדפיסה דבר.
3. **מילון רשימות — הנתונים לפני הטבלה:** הצג `data` עם 3 מפתחות ו־4 ערכים בכל רשימה. צייר מתחת לכל מפתח **רק** את שמו של השדה; אין חצים לתוך הקוד. הראה התאמה של כל אינדקס: 0=נועה/2/65, 1=איתי/4/82, 2=שיר/3/74, 3=עומר/5/91.
4. **איך מילון הופך לטבלה?** הצג קלט מילון משמאל ופלט טבלה מימין באמצעות שני מלבנים נפרדים; חץ יחיד באמצע עם תווית ״יצירת DataFrame״ — לא על הקוד.
5. **`df = pd.DataFrame(data)` — פירוק פקודה:** בשורה אחת קריאה וברורה. טבלת הסבר מתחת: `df` משתנה; `=` השמה; `pd` ספרייה; `.` גישה; `DataFrame` מבנה טבלה; `(data)` נתוני הקלט. אין יותר משש שורות הסבר.
6. **קוד מלא ופלט מלא:** הצג `import pandas as pd`, את המילון ואת `df=pd.DataFrame(data)`, ואז `print(df)` בטור אחד; בצד שני טבלה ברורה 4×3. הדגש שהתלמידים עם השמות והציונים הנכונים בשורות 0–3. **הקוד צריך להיות גדול וקריא, ללא חץ או תווית בתוכו**.
7. **מה פירוש `shape` ב־DataFrame?** חזור ל־NumPy: `X.shape=(4,2)`; כעת `df.shape=(4,3)`, כי יש `name,hours,score`. השווה בעזרת שני איורי תאים נקיים. בתחביר נכון יש לכתוב `print(df.shape)` ולא לבצע השמה ל־`df.shape`.
8. **CSV הוא קובץ נתונים:** הצג טקסט קצר, *בדיוק*:
   ```csv
   name,hours,score
   Noa,2,65
   Itay,4,82
   Shir,3,74
   Omer,5,91
   ```
   הבהר כי השמות בלועזית בדוגמה הזאת הם ייצוג קובץ בלבד; שמות העמודות נשארים זהים. פירוק שורת כותרת, פסיקים ושורה אחת לכל תצפית; CSV אינו קובץ Excel.
9. **`pd.read_csv(url)` — עיקרון הטעינה:** הצג `url = "https://raw.githubusercontent.com/samiabo75/Data-Science-ML-Course/main/Datasets/penguins.csv"`, אחריו `penguins = pd.read_csv(url)`. פרק `pd`, `read_csv`, `url`; הפלט הוא DataFrame. הראה את שמות העמודות האמיתיים במאגר: `species,island,bill_length_mm,bill_depth_mm,flipper_length_mm,body_mass_g,sex`. אין להמציא רשומות או להראות פתרון מעבדה.
