## הדגמה מדורגת — קוד למורה
```python
import pandas as pd
df = pd.DataFrame({
    "name": ["אורי", "מאיה", "נטע", "רון"],
    "practice_hours": [2, 4, 3, 5],
    "score": [65, 82, 74, 91]
})
print(df.shape)                # (4, 3): name היא גם עמודה!
print(df[["practice_hours", "score"]].shape)  # (4, 2)
print(df["score"].shape)      # (4,)
print(df[["score"]].shape)    # (4, 1)
mask = df["score"] >= 80
print(mask.tolist())          # [False, True, False, True]
print(df.loc[mask, ["name", "score"]])
```
שימו לב: מטריצת המקור ממפגש 5 היא 4×2; בטבלת Pandas שלנו התווסף שדה `name`, לכן ה־DataFrame המלא הוא 4×3. זו נקודת עצירה מצוינת למניעת בלבול.

## הסבר מתמטי והקשר AI
- מטריצת המאפיינים: `X∈ℝ^(n×m)`; `n` דוגמאות ו־`m` מאפיינים מספריים.
- המסכה `mᵢ = (scoreᵢ ≥ 80)` מחזירה אמת/שקר לכל שורה, *לא הסתברות*.
- שיעור הדוגמאות שעומדות בתנאי: `2/4×100%=50%`, **רק במדגם ההמחשה**.
- ממוצע ציונים: `(65+82+74+91)/4=78`; פירוש: ממוצע נתוני הטבלה, לא ציון חזוי.
- חיבור ל־ML: טבלת נתונים מסודרת מאפשרת להגדיר מראש `X` (מאפיינים) ו־`y` (יעד). אין להזין שם תלמיד כמספר בלי משמעות; אין להכניס את היעד עצמו למאפיינים. לפני אימון נדרשים טיפול בחסרים, חלוקת נתונים והחלטת מדד — בשיעורים מאוחרים.

## מוקשים פדגוגיים
- `shape` סופר גם עמודות טקסט של DataFrame; `(4,3)` כאן אינו סותר `(4,2)` של המטריצה המספרית.
- `df["score"]` מחזיר Series; סוגריים כפולים מחזירים DataFrame.
- `df["score"] >= 80` מחזיר מסכה; `df[df["score"] >= 80]` מסנן טבלה.
- `head()` מציג רק תחילת טבלה; אינו מוחק שורות ואינו מדגם מייצג.
- `info()` מציג טיפוסים וספירת ערכים לא חסרים; `describe()` מתאר נתונים מספריים כברירת מחדל. אף אחד מהם לא מוכיח קשר סיבתי.
- `DataFrame` יכולה להיווצר ישירות מרשימות Python. `to_numpy()` אופציונלית לצורך חישוב מספרי ספציפי.
