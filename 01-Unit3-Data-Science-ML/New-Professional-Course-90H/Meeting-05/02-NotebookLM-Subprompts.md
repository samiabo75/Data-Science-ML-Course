## פרומפט עצמאי: 5א־1 — מה־list ללולאת for (9 שקפים)

**המקור:** המצגת שהופקה From_Lists_to_NumPy_Arrays, שקפים 1–3, וכן 01-Teacher-Guide.md. **הדמות:** מיה, מרכזת חוג המדעים. **תוצאה מדידה:** התלמיד עוקב אחרי לולאה שמוסיפה 5 נקודות לרשימה.
1. סיפור קצר: ציונים [70,80,90]; מה רוצים לשנות ומה לא?
2. `list` ואינדקסים 0,1,2; גישה `scores[1]` ומה משמעות הפלט 80.
3. הצג למה `scores + 5` **אינה חוקית** ב־Python list; הראה TypeError בלי להעמיס traceback.
4. הראה פתרון מוכר: יצירת `updated=[]`, והסבר למה שומרים תוצאה בנפרד.
5. לולאה בחלקים: `for i in range(len(scores)):`; פרק `for`, `i`, `in`, `range`, `len`, `:` והזחה.
6. `updated.append(scores[i]+5)`: פרק `append`, הנקודה, האינדקס, החיבור והסוגריים.
7. טבלת עקיבה **מלאה** לשלושת הערכים: i, scores[i], תוצאה, updated אחרי כל מעבר: [75] → [75,85] → [75,85,95].
8. קוד מלא קצר ופלט; הדגש שהרשימה המקורית `scores` נשארת [70,80,90] בפתרון זה.
9. בדיקת הבנה: מה יקרה אם נחליף +5 ב־+3? רמז, בלי לפתור את דף המעבדה.
קוד הדגמה המחייב:
```python
scores = [70, 80, 90]
updated = []
for i in range(len(scores)):
    updated.append(scores[i] + 5)
print(updated)
```
פלט: `[75, 85, 95]`. **משפט מעבר:** אפשר להגיע לתוצאה גם בלי לכתוב את הלולאה בעצמנו — בחלק הבא נבין כיצד.

## פרומפט עצמאי: 5ד — ממרחק יחיד למרחק מכל שורה (10 שקפים)

**המקורות:** שיעור 5ד שהועלה ומדריך המורה. **דוגמה:** `X=[[1,2],[4,6],[1,5]]`, `q=[1,2]`.
1. בעיה: במקום למדוד מרחק אחד, צריך שלושה מרחקים.
2. הצג מטריצה (3,2), וקטור (2,) ופירוש הממדים.
3. פתרון מוכר ב־for: `for i in range(len(X))` ו־`X[i]`; פירוק מילולי.
4. חישוב בכל מעבר ושמירה ב־`distances_loop.append(d)`; טבלת עקיבה: [0] → [0,5] → [0,5,3].
5. `X-q` באמצעות broadcasting. הסבר שהווקטור נלקח רעיונית מול כל שורה בלי לשנות פיזית את X או q.
6. מטריצת ההפרשים `[[0,0],[3,4],[0,3]]`; להראות כל זוג מול השורה המתאימה.
7. `np.linalg.norm(X-q,axis=1)`: פירוק מלא; `axis=1` נותן מרחק לכל **שורה**, והפלט [0.,5.,3.]. ללא axis תתקבל נורמה אחת למטריצה.
8. `np.argmin(distances)`: מחזיר **אינדקס** 0, לא ערך 0; `X[0]=[1,2]`.
9. מקרה תיקו קטן נפרד: שתי רשומות באותו מרחק; `argmin` מחזיר מיקום ראשון. אל תטען ליחידות.
10. הכנה ל־KNN: למה לפני סיווג צריך לבחור תכונות בעלות משמעות, לטפל בסקאלות ולדעת תוויות? אין אימון מודל עדיין.
הציגו קוד:
```python
distances_loop = []
for i in range(len(X)):
    d = np.linalg.norm(X[i] - q)
    distances_loop.append(d)
distances = np.linalg.norm(X - q, axis=1)
```
