## כלל הפירוק הנדרש לכל פקודה
בכל הופעה ראשונה של פקודת Python חדשה, הצג **חמש שכבות**: (1) איזו בעיה הפקודה פותרת; (2) פירוק מילולי לכל שם, נקודה, סוגריים, פסיק, אופרטור ופרמטר; (3) עקיבה של ערכי קלט וביניים; (4) פלט **אמיתי** והסבר יחידות, ממדים וסוג התוצאה; (5) שאלת ״מה יקרה אם נשנה...?״ בלי פתרון התרגול העצמאי. המורה מסביר בעל פה, השקף מציג רק קוד קצר ותמונה/טבלה אחת.

### 5א — תיקון סדר שקפים
שקף 1: בעיית מיה — להוסיף חמש נקודות לשלושה ציונים. שקף 2: פתרון **לולאת for רגילה** כפי שלמדו ב־Python ובדומה ל־Java:
```python
scores = [70, 80, 90]
updated = []
for i in range(len(scores)):
    updated.append(scores[i] + 5)
print(updated)
```
פירוק חובה: `range` טווח אינדקסים, `len` מספר איברים, `scores[i]` איבר מספר i, `append` הוספת איבר לרשימה. שקף 3: טבלת עקיבה i=0,1,2 ותוצאה [75,85,95]. שקף 4: יצירת `np.array` ופירוק `import numpy as np`, `np`, נקודה, `array(...)`. שקף 5: `a+5` לעומת שרשור רשימות. שקף 6: וקטור אחד `(2,)`. שקף 7: מטריצה של שלוש תצפיות ושני מאפיינים, `shape=(3,2)`. שקף 8: `X[1,0]` והדגשת התא הנכון. שקף 9: בדיקת הבנה ומעבר. **אל תציג כפל מטריצות** כאילו הוא אותה פעולה.

### 5ב — קודם FOR ואז פעולה וקטורית
הצג את החישוב על איברי `[70,80,90]` בלולאת `for` וטבלת עקיבה; אחר כך `np.array` ו־`a+5`. בהופעת `np.mean(a)`, פרק את הקלט, הממוצע `(70+80+90)/3=80` והפלט המספרי. בהופעת `pd.DataFrame` הסבר שכל מפתח במילון הוא שם עמודה וכל רשימה היא ערכי העמודה. אין צורך להמיר אותה ידנית לפני Pandas. `to_numpy()` מחזירה מערך לפי צורך, ויכולה להיות בעייתית בנתונים מטיפוסים מעורבים.

### 5ג — משפט פיתגורס ואז נורמה
לכל רכיב של `np.linalg.norm(a-b)` הצג פירוק: `a-b` הוא וקטור ההפרשים; `np.linalg` כלי אלגברה ליניארית; `norm` אורך הווקטור. קודם חשב ידנית `a=(1,2)`, `b=(4,6)`: הפרשים `(-3,-4)`, ריבועים `9,16`, סכום 25, שורש 5. הצג בגרף שתי נקודות לפי צירים זהים; שאל האם אפשר להשוות מטרים לשקלים בלי התאמת סולם.

### 5ד — חובה השוואה בין שתי דרכי חישוב
למד קודם חישוב מרחק מכל שורה בלולאה:
```python
distances_loop = []
for i in range(len(X)):
    d = np.linalg.norm(X[i] - q)
    distances_loop.append(d)
```
הסבר `X[i]` שורה אחת, `-q` הפרש רכיבי, `norm` מרחק, `append` איסוף התוצאות. לאחר מכן:
```python
distances = np.linalg.norm(X - q, axis=1)
```
פירוק: `X-q` מפחית את q מכל שורה באמצעות broadcasting; `axis=1` מבקש נורמה לכל שורה, ולא נורמה אחת של כל המטריצה. הקוד המקוצר מחשב את אותה תוצאה עבור הקלט שהוגדר, אינו משנה את נתוני המקור. לבסוף `np.argmin(distances)` מחזירה את **האינדקס** של המינימום הראשון, ולא את ערך המינימום. הדגם תיקו אפשרי, בלי לקבוע כי יש שכן יחיד כשיש שוויון.
