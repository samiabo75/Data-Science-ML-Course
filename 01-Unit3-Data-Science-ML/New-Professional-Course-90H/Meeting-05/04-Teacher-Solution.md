## 1. רשימה ומערך
```python
import numpy as np
hours_list = [2, 5, 4, 8]
hours_array = np.array(hours_list)
print(hours_array)
print(hours_array + 1)
```
פלט: `[2 5 4 8]` ואז `[3 6 5 9]`.
הסבר: הסוגריים של list והמספרים המופרדים בפסיקים שונים מהצגת ndarray. `hours_list + [1]` נותנת רשימה `[2,5,4,8,1]` (שרשור) ולא תוספת 1 לכל ערך; `hours_list + 1` מעלה TypeError.

## 2. וקטור ומטריצה
```python
noam = np.array([2, 4])
students = np.array([[2, 4], [5, 8], [4, 4], [8, 7]])
print(noam.shape)       # (2,)
print(students.shape)   # (4, 2)
print(students[1, 1])   # 8
```
`students[2,0]=4` (תמר, שעות אימון). הדגישו אינדקס אפס; הצורה של וקטור חד־ממדי היא `(2,)`, לא `(1,2)`.

## 3. Pandas
```python
import pandas as pd
df = pd.DataFrame({"hours":[2,5,4,8], "interest":[4,8,4,7]})
print(df.shape)                     # (4, 2)
numbers = df[["hours", "interest"]].to_numpy()
print(numbers.shape)                # (4, 2)
```
פנדס מקבלת רשימות ישירות. `to_numpy()` כאן בחירה לצורך חישוב NumPy ולא שלב חובה לפני יצירת DataFrame.

## 4. מרחק ביד
חדש `(3,5)`, נועם `(2,4)`. הפרשים `3-2=1` ו־`5-4=1`. ריבועים `1` ו־`1`, סכום `2`, שורש `√2≈1.414`. המרחק הוא ערך גאומטרי על שני המדדים; אין זו הסתברות לדמיון.

## 5. מרחק אחד
```python
new_student = np.array([3,5])
noam = np.array([2,4])
distance = np.linalg.norm(new_student - noam)
print(round(distance,3))
```
פלט `1.414`. סדר החיסור לא משנה את המרחק בגלל הריבועים, אך משנה את סימני וקטור ההפרשים.

## 6. מרחק לכל שורה
```python
diff = students - new_student
distances = np.linalg.norm(diff, axis=1)
closest_index = np.argmin(distances)
print(np.round(distances, 3))
print(closest_index)
print(students[closest_index])
```
הפרשים: `[[-1,-1],[2,3],[1,-1],[5,2]]`. ריבועי סכומים: `[2,13,2,29]`. מרחקים: `[1.414,3.606,1.414,5.385]`. `np.argmin` מחזיר **0**, כי יש תיקו בין נועם ותמר ו־NumPy מחזיר את מיקום המינימום הראשון. השורה הקרובה לפי הפלט: `[2,4]`, אך **יש עוד שורה באותו מרחק**. אל תגידו שנועם קרוב באופן יחיד.
`axis=1` אומר הפעלת נורמה על כל שורת ההפרשים בנפרד. בלעדיו תתקבל נורמה אחת לכל המטריצה. אם אחת התכונות ביחידות של אלפים, יש לשקול טיפול בקנה המידה לפני השוואת מרחקים.

## תשובת יציאה ומשוב
`list` לאוסף כללי; `ndarray` לחישוב מספרי וממדים; `DataFrame` לטבלה עם שמות עמודות ואינדקסים. ״הכי קרוב״ תלוי בתכונות, ביחידות ובמדד; הוא אינו הוכחה לזהות בהעדפות או בקטגוריה. 
**בדיקת מורה:** חישוב ידני, התאמת פלט, משמעות `shape`, אינדקסים, `axis=1`, מודעות לתיקו ולהשפעת הסקאלה.
