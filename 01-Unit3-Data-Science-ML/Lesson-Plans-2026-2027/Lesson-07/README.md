העוגן הוא קריאת CSV והיכרות עם Penguins בסיכום מפגש 2. נלמד מקור וגרסה, read_csv, פירוש ממדים ויחידות, מגבלות הצצה וערך חסר. info היא הרחבה.
הפעם משתמשים בנתונים אמיתיים הקיימים במאגר; המחברות הן התאמה שלנו, לא מחברות מקור של המרצה. מקור הנתונים והייחוס במערך ובמחברות.
Penguins כוללת 344 רשומות, ולכן אינה מוצגת כמאגר גמר מתאים לרף 1000 הרשומות שתועד בקטלוג ההשתלמות.

## אימות
קישור Raw החזיר HTTP 200 ונטען ישירות ב־pandas. קוד ההדגמות והפתרון הורץ ברצף ב־Python; נבדקו ממדים, עמודות, חסרים ו־head/tail. לצורך בדיקת מסוף display הוחלפה ב־print; תצוגת HTML וממשק Colab לא נבדקו. נבדק מבנה JSON בסיסי, ללא אימות סכמת nbformat מלאה. תאי ההשלמה נשארו ריקים בכוונה.
הפתרון גלוי במאגר הציבורי. המקורות נשמרו ללא שינוי.
