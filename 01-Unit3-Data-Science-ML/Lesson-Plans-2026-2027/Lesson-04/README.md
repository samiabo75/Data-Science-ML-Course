## התאמה לתלמידים
בהשתלמות הונח ידע Python קודם; כאן לומדים לאט, מהדפסה של ערך בכל מעבר לחישוב גיל לכל תצפית. צבירה מסומנת כהרחבה מותנית שאפשר להעביר למפגש הבא.
כל הנתונים מומצאים; אין CSV חיצוני או אימון מודל. התרגילים הם עיבוד שלנו המעוגן בחומרי המאגר, כמפורט במדריך; לא התקבלה מחברת מקור חדשה.

## בדיקות
קוד ההדגמות והפתרון הורץ ברצף ב־Python, עם בדיקת פלט ותוצאות צפויות. תא תרגול מודרך נשאר להשלמת התלמיד. מבנה JSON בסיסי נבדק; לא בוצע אימות סכמת nbformat מלאה או הרצה בממשק Colab.
הפתרון גלוי במאגר הציבורי. יצירת הערכה אינה דיווח על הוראתה בפועל.
