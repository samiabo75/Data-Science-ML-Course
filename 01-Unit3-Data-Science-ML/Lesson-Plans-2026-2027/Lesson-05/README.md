פותחים בצורך לבחור מחירים שעומדים בתקציב. לומדים השוואה, True/False, תנאי if על ערך אחד, ואז שילוב עם for. ספירת התאמות היא רשות בלבד ואין צורך בידע בצבירה למשימות הליבה.

העוגן הוא סיכום מפגש ההשתלמות 2, שבו מופיעים תנאים וסינון טבלאי; פירוט במערך. התרגילים הם התאמה שלנו, לא תרגילי מקור. כל הנתונים מומצאים, ואין CSV חיצוני.
הקוד המודרך והפתרון נבדקו בהרצה רציפה ב־Python, כולל ערכי סף ואי־שינוי מקור. נבדק מבנה JSON בסיסי; לא אומתה סכמת nbformat מלאה ולא בוצעה הרצה בממשק Colab.
הפתרון גלוי במאגר הציבורי. תאי השלמה נשארו ריקים בכוונה.
