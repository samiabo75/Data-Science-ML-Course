## בדיקות
קוד ההדגמות והפתרון הורץ ב־Python מול CSV חי. נבדקו המסכות, קבוצות צפויות, גבולות, ממדים, אינדקסים ושמירת המקור. display הוחלפה ב־print לבדיקת מסוף; תצוגת HTML וממשק Colab לא נבדקו. נבדק JSON בסיסי ללא סכמת nbformat מלאה; תאי ההשלמה ריקים בכוונה.
הפתרון גלוי במאגר הציבורי. נתוני Penguins נשמרו ללא שינוי, מקור וייחוס במערך ובמחברות.
