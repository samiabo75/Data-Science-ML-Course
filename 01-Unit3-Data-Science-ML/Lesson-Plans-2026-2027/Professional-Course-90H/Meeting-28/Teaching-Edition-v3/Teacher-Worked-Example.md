# תרגיל מורה ופתרון מדורג — מפגש 28

## סיפור ושאלה
תלמידת פרויקט רוצה להציג את ביצוע המודל הסופי, אך כבר ניסתה לשנות אותו לאחר שראתה את Test.

## פתרון ידני/אלגוריתמי והמשמעות
בחירת המודל מתבצעת בנתוני פיתוח וב־CV. לאחר נעילת הבחירה יוצרים פעם אחת תחזיות Test, מודדים ואז מתעדים מגבלות. אין נוסחה חדשה; זו שרשרת החלטות.

| שלב | מה כותבים על הלוח? | מה בודקים? |
|---|---|---|
| 1 | השאלה, התצפיות, התכונות והיעד | האם כל נתון קיים ומתועד? |
| 2 | נוסחה/תרשים תהליך לפי המקור | הגדרת כל סימן, מכנה, יחידה או תנאי |
| 3 | הצבה מספרית והפרדת חישוב לשורות | האם סדר הפעולות תקין? |
| 4 | התוצאה והמשמעות בהקשר המחקר | מה נמדד ומה רק נחזה? |
| 5 | בדיקת הקוד במחברת המודרכת | האם אותה שיטה מוציאה אותה תוצאה? |
| 6 | שיפור/הסתייגות | אין לכוונן לפי Test ולהציג את אותו Test כמדד סופי בלתי תלוי. |
