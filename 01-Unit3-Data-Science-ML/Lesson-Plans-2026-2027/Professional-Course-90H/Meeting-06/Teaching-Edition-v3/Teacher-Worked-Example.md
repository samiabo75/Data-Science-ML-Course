# מפגש 6 — פתרון ידני, חיתוך מסכות והעברה למאגר אמיתי (למורה)

## 1. מחשבים: תחום המחיר
ההצעות המומצאות A=1000, B=2500, C=4000, D=4500 ש״ח, וזיכרונות מתאימים 16,8,32,16 GB.

\[
I_i=\mathbf{1}[p_i\ge1500]\land\mathbf{1}[p_i\le4000].
\]

| מזהה | \(p_i\) | תנאי תחתון | תנאי עליון | AND |
|---|---:|---|---|---|
| A | 1000 | False | True | False |
| B | 2500 | True | True | True |
| C | 4000 | True | True | True |
| D | 4500 | True | False | False |

לכן נבחרות שתי שורות B,C, ומתקבלת טבלה (2,3). שיעור הנבחרות 2/4×100=50% **רק מתוך ארבע ההצעות המומצאות**. מיון יורד מציג את **C, 32GB, 4000 ש״ח** לפני **B, 8GB, 2500 ש״ח**. מזהה וזיכרון חייבים לעבור יחד עם המחיר. שינוי הגבול העליון ל־<4000 משאיר רק B.

## 2. בדיקת קובץ Penguins של הקורס
נשלף ונבדק ישירות קובץ Datasets/penguins.csv (27.10.2026), 344×7:

- Adelie — 152 רשומות;
- flipper_length_mm≥190 — 265 רשומות;
- Adelie **וגם** flipper_length_mm≥190 — **86** רשומות;
- bill_length_mm בין 40 ל־45 כולל — **77** רשומות;
- flipper_length_mm חסר בשתי רשומות.

שימו לב: 86≤152 וגם 86≤265 — חיתוך **אינו גדול** מאחת הקבוצות שלו. 77 מתייחס למדידות מקור ידועות שמקיימות את שני הגבולות. שתי מדידות אורך סנפיר חסרות אינן עדות לאורך קצר.

## 3. למה לא מדגם מייצג?
מיון לפי מסה בסדר יורד ו־head(5) בוחר בכוונה את חמש רשומות הקצה עם המסה הגבוהה ביותר מתוך הקבוצה. הוא **אינו דגימה אקראית**, ולכן לא נכון להשתמש בחמש אלה כאילו הן מייצגות את התפלגות כל הפינגווינים.

## 4. Diamonds — אימות מתוכנן בעת טעינה
המקור הממופה למחברת ההשתלמות הוא https://raw.githubusercontent.com/arielb30/datasets/main/diamonds.csv . המאגר המקורי המוכר של ggplot2 מתועד כ־53,940×10, עם carat,cut,color,clarity,depth,table,price,x,y,z. קובץ arielb30 הספציפי אינו זמין לקריאה מלאה בסביבת הבדיקה הנוכחית, ולכן **אין טענה לספירות קבוצות מאומתות כאן**. לאחר טעינת הקובץ במחברת המורה ב־Colab, מאמתים את המבנה ואת הספירה ל־Ideal וגם carat≥1 ואת טווח 0.5–0.7 קראט בפלט החדש. שימוש בנתוני מחיר היסטוריים אינו מחירון עדכני או תחזית.

## 5. תיקון תקלה מן המקור
בתא דוגמת המסכות במחברת Guided המקורית מופיעה השמה המשנה את מחיר כל המחשבים ושימוש במשתנה memory_mask לפני הגדרתו. יש להחליפה בשתי **השוואות** ובחיבור AND, כפי שמודגם במחברת Audited החדשה; אין לשנות את המקור הישן ללא תיעוד.
