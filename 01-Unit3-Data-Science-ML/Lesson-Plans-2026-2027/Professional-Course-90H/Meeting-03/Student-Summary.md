# מפגש 3 — תנאי פשוט וטבלת הנתונים הראשונה
## סיפור המסגרת ושאלת הלמידה
דודו בוחר מחשב שעומד בתקציב. תחילה נגדיר תנאי ברור, ובהמשך נראה מדוע כדאי לארגן את כל המחשבים כשורות בטבלה.

## מה נלמד ומדוע
if בודקת תנאי שערכו True או False. סימן = משייך ערך, ואילו == בודק שוויון. DataFrame היא טבלת נתונים. shape מתארת מספר שורות ועמודות, ו־ head מציגה התחלה בלי למחוק שורות. בכל טבלה מגדירים מה נחשבת תצפית.

## דוגמה פתורה קטנה
מחשב שמחירו 2400 שקלים עומד בתנאי מחיר שאינו עולה על 2500. זו בחירה לפי כלל, לא תחזית של המחיר.

```python
price = 2400
if price <= 2500:
    print("Within budget")
```

**פלט צפוי ופירוש:** Within budget. זוהי דוגמה קטנה ומוצהרת; היא אינה ציון ביצוע של פרויקט אמיתי.

עבדו לפי הסדר: נסחו את השאלה, זהו נתונים ויחידות, בחרו כלי שכבר נלמד, כתבו ציפייה, הריצו והסבירו תוצאה ומגבלה. במשימה שאינה מובנת חוזרים למושג או לדוגמה, ולא מחפשים שורת קוד להעתקה.
