## סיפור המסגרת ושאלת הלמידה
במועדון שואלים כמה תלמידים בחרו בכל פעילות וכיצד זמני ההגעה מתפלגים. לשתי השאלות נבחר גרפים שונים.

## מה נלמד ומדוע
משתנה קטגוריאלי מתאר קבוצה, ומשתנה כמותי מתאר כמות או מדידה. Countplot סופרת רשומות בכל קטגוריה. היסטוגרמה מחלקת מדידה לתחומי ערכים וסופרת בכל תחום. סוג המשתנה נקבע לפי המשמעות ולא רק לפי טיפוס האחסון. כל גרף צריך שאלה, צירים ופירוש.

## דוגמה פתורה קטנה
בערכים 10, 12, 18 ו־ 22, התחום 10 עד פחות מ־ 20 מכיל שלוש תצפיות. התחום הבא מכיל אחת. אלה תחומי מדידה ולא שמות קבוצות.

```python
values = [10, 12, 18, 22]
count = 0
for value in values:
    if 10 <= value < 20:
        count = count + 1
print(count)
```

**פלט צפוי ופירוש:** 3. זוהי דוגמה קטנה ומוצהרת; היא אינה ציון ביצוע של פרויקט אמיתי.

עבדו לפי הסדר: נסחו את השאלה, זהו נתונים ויחידות, בחרו כלי שכבר נלמד, כתבו ציפייה, הריצו והסבירו תוצאה ומגבלה. במשימה שאינה מובנת חוזרים למושג או לדוגמה, ולא מחפשים שורת קוד להעתקה.
