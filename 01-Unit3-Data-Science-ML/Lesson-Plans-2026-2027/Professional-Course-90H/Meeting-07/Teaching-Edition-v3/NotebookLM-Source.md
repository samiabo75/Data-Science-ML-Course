## נתוני הדגמה — מומצאים ומוצהרים
סקר מועדון: רובוטיקה, ספורט, רובוטיקה, מוזיקה, ספורט, רובוטיקה. שכיחויות 3,2,1, סך 6. שכיחות יחסית לרובוטיקה 3/6×100=50% משש התשובות בלבד.

זמני הגעה בדקות [10,12,18,22]. תחומים [10,20),[20,30): ‏[3,1], סך 4. כאשר בוחרים תחומים [10,15),[15,20),[20,25),[25,30): ‏[2,1,1,0], סך 4. שתי התצוגות מתארות **אותן ארבע מדידות**.

נוסחאות לניתוח ידני:
\[
f_j=\sum_{i=1}^n\mathbf{1}[x_i=j],\qquad
h_j=\sum_{i=1}^n\mathbf{1}[a_j\le x_i<b_j].
\]

יש להסביר כל סימן: n מספר תצפיות; x_i ערך בשורה i; 1 כאשר התנאי מתקיים; התחום [a,b) כולל גבול שמאלי ולא ימני, למעט הקצה האחרון במימוש histogram כאשר ישנו.

~~~python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
club_df = pd.DataFrame({"activity":["Robotics","Sports","Robotics","Music","Sports","Robotics"]})
sns.countplot(data=club_df,x="activity")
plt.xlabel("Activity")
plt.ylabel("Number of answers")
plt.show()
~~~

~~~python
arrival_minutes = [10,12,18,22]
plt.hist(arrival_minutes,bins=[10,20,30])
plt.xlabel("Arrival time (minutes)")
plt.ylabel("Observations per interval")
plt.show()
~~~
