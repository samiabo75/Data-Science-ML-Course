# שער רינדור חזותי להמחשות SVG — מפגשים 17–23
**מטרה:** בדיקת יכולת הרינדור של 13 איורים ויצירת תצוגת גלריה שאפשר להגהה שקף־שקף.

## מה מתבצע אוטומטית?
הסקריפט `scripts/render_svg_quality_gate.py` פותח כל SVG כתוכן XML, בודק קיום שורש `<svg>` וממדים, מרנדר קובץ PNG בעזרת CairoSVG, מוודא ממדי פיקסלים מינימליים, ומייצר:
- `render-report.json` — PASS/FAIL לכל איור.
- `Meeting-XX_<name>.png` — תמונת רינדור לכל SVG.
- `all-meetings-contact-sheet.png` — גלריה של 13 התמונות להגהה מרוכזת.

הקבצים נוצרים תחת `svg-render-output/` במהלך GitHub Actions ומועלים כ־Artifact; אין צורך ליצור תיקיית איורים נוספת בתוך המאגר. הוראות הפעלה: GitHub Actions → `Unit3 Meetings 17-23 SVG render gate` → `Run workflow`, או להריץ מקומית לאחר התקנת CairoSVG ו־Pillow.

## מה הבדיקה אינה מוכיחה?
גם רינדור PASS **אינו מוכיח** שהטקסט אינו חופף, שהעברית והנוסחאות קריאות בהקרנה, שהצבעים מתאימים לעיוורון צבעים, או שהמצגת שנוצרה ב־NotebookLM נכונה. יש להוריד את ארטיפקט התצוגה ולעבור על 13 התמונות, ולאחר מכן להפיק ולבדוק מצגות שקף־שקף.

## מחוון מורה לבדיקה ידנית
לכל PNG סמנו: 1. מספרים מול מסמך המקור; 2. אמת בשורות וחיזוי בעמודות כשצריך; 3. יחידות ותוויות; 4. היעדר חפיפת מילים/חצים; 5. קריאות בעברית RTL ולטקסט אנגלי LTR; 6. ניגודיות ברקע בהיר; 7. אין מפתח תרגיל עצמאי.
תעדו איור, תקלה ותיקון ב־Quality-Check.md של המפגש. **מעמד חזותי נשאר Pending human review עד בדיקה אמיתית.**
