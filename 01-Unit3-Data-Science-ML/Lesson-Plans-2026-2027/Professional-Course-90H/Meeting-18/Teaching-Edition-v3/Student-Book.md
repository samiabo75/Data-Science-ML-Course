## 3. טבלת אמת מול חיזוי — ידנית לפני קוד
דוגמת המורה המומצאת (לא נתוני Penguins):
| מוצר | אמת (actual) | תחזית (predicted) | פירוש |
|---|---|---|---|
| 1 | OK | OK | תקין שזוהה כתקין |
| 2 | OK | OK | תקין שזוהה כתקין |
| 3 | OK | Defect | התראת שווא |
| 4 | OK | OK | תקין שזוהה כתקין |
| 5 | Defect | OK | פגם שהוחמץ |
| 6 | Defect | OK | פגם שהוחמץ |
| 7 | Defect | Defect | פגם שזוהה |
| 8 | Defect | Defect | פגם שזוהה |

**מחלקה חיובית: Defect.** המילים חיובי ושלילי הן הגדרות של מחלקות, לא שיפוט ערכי.
- **TN (True Negative)**: תקין בפועל, תקין בחיזוי — 3.
- **FP (False Positive)**: תקין בפועל, פגום בחיזוי — 1. *התראת שווא.*
- **FN (False Negative)**: פגום בפועל, תקין בחיזוי — 2. *החמצת פגם.*
- **TP (True Positive)**: פגום בפועל, פגום בחיזוי — 2.

## 4. בניית המטריצה
**שורות = אמת; עמודות = חיזוי; סדר תוויות = [OK, Defect].**

| אמת \ חיזוי | OK | Defect | סה״כ אמת |
|---|---:|---:|---:|
| OK | TN = 3 | FP = 1 | 4 |
| Defect | FN = 2 | TP = 2 | 4 |
| **סה״כ חיזוי** | **5** | **3** | **8** |

כל תצפית נכנסת לתא אחד בלבד. סכום התאים = 3+1+2+2=8. האלכסון הראשי = תחזיות נכונות = 3+2=5.

![דוגמה חזותית](confusion-matrix-binary-eight.svg)

## 5. הנוסחה: Accuracy
\[
Accuracy=\frac{TP+TN}{TP+TN+FP+FN}=\frac{2+3}{2+3+1+2}=\frac58=0.625=62.5\%.
\]

המונה סופר את התחזיות הנכונות והמחנה את כל תצפיות הבדיקה. תאי המטריצה הם **מספר מוצרים**, לא אחוזים. אחוז ההצלחה לבדו אינו מבהיר מהן הטעויות.

## 6. בודקים בקוד
```python
import pandas as pd
from sklearn.metrics import confusion_matrix, accuracy_score

actual = ["OK","OK","OK","OK","Defect","Defect","Defect","Defect"]
predicted = ["OK","OK","Defect","OK","OK","OK","Defect","Defect"]
labels = ["OK", "Defect"]

cm = confusion_matrix(actual, predicted, labels=labels)
table = pd.DataFrame(cm, index=labels, columns=labels)
table.index.name = "Actual"
table.columns.name = "Predicted"
display(table)
print("Total:", cm.sum())
print("Accuracy:", accuracy_score(actual, predicted))
assert cm.tolist() == [[3, 1], [2, 2]]
assert cm.sum() == len(actual)
assert accuracy_score(actual, predicted) == 5 / 8
```

**פלט צפוי:** מטריצה `[[3, 1], [2, 2]]`, מספר תצפיות 8, Accuracy 0.625. כאן אין מודל מאומן; הנתונים מומצאים כדי ללמוד לקרוא תחזיות.

## 7. למה חייבים להגדיר מחלקה חיובית?
אם נגדיר OK כחיובי, *ספירת השורות והעמודות באותה מטריצה אינה משתנה*, אך התפקידים TP/TN ו־FP/FN מתחלפים. אין להשוות FP ו־FN של שני דיווחים בלי לדעת מה הוגדר כחיובי. בסיווג רב־מחלקתי (שלושה מיני Penguins) קוראים תחילה מטריצה 3×3; להגדרת FN למין יחיד מתייחסים אליו כאל המין הנבחר מול כל האחרים.
