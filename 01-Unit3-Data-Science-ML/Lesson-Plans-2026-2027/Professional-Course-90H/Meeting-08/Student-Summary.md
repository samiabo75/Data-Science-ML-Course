# מפגש 8 — מרכז, פיזור והיכרות עם נורמלית
## סיפור המסגרת ושאלת הלמידה
לשתי קבוצות זמן הגעה ממוצע זהה לבית הספר, אך בקבוצה אחת הזמנים מפוזרים הרבה יותר. נבחן מה הממוצע מסתיר.

## מה נלמד ומדוע
ממוצע הוא סכום חלקי מספר ערכים. חציון הוא האמצע לאחר מיון. שונות ממוצעת ריבועי סטיות, וסטיית תקן היא השורש שלה וביחידות המקור. ddof=0 מתאר כאן את הרשימה המלאה. ddof=1 משמש באומדן שונות מדגם. התפלגות נורמלית סימטרית ודמוית פעמון; תקנון אינו מוכיח נורמליות.

## דוגמה פתורה קטנה
לרשימה [10,20,30] ממוצע 20. ריבועי הסטיות הם 100,0,100, ולכן השונות 200/3 וסטיית התקן כ־ 8.165. לרשימה [18,20,22] אותו מרכז ופיזור קטן יותר.

```python
import numpy as np
values = np.array([10., 20., 30.])
print(values.mean())
print(values.std(ddof=0))
```

**פלט צפוי ופירוש: ** 20.0
8.16496580927726. זוהי דוגמה קטנה ומוצהרת; היא אינה ציון ביצוע של פרויקט אמיתי.

עבדו לפי הסדר: נסחו את השאלה, זהו נתונים ויחידות, בחרו כלי שכבר נלמד, כתבו ציפייה, הריצו והסבירו תוצאה ומגבלה. במשימה שאינה מובנת חוזרים למושג או לדוגמה, ולא מחפשים שורת קוד להעתקה.
