# מפגש 27 — SVM והשוואת מודלים
## סיפור המסגרת ושאלת הלמידה
כמה קווים יכולים להפריד בין דוגמאות. SVM מציע רעיון של שוליים ופשרה בין רוחב ההפרדה לבין מחיר חריגות.

## מה נלמד ומדוע
SVM ליניארי לומד גבול החלטה. C שולט בפשרת הענישה. decision_function מחזיר ציון חתום ולא הסתברות. משווים מסווגים באותן חלוקות ובאותו מדד. אין הבטחת דיוק, ואין צורך להעמיק בכל סוגי kernels כדי להבין את המודל הבסיסי.

## דוגמה פתורה קטנה
ציון +0.7 מתאר צד של גבול לפי סדר המחלקות, ואינו אומר הסתברות של 70%. קוראים classes_ לפני שמפרשים את הסימן.

```python
scores = [-0.2, 0.7]
for score in scores:
    print("negative side" if score < 0 else "non-negative side")
```

**פלט צפוי ופירוש: ** negative side
non-negative side. זוהי דוגמה קטנה ומוצהרת; היא אינה ציון ביצוע של פרויקט אמיתי.

## הדרך לתרגול העצמאי
Pipeline נתון, SVC ליניארי, מטריצה וציון חתום. C קבוע כאן מראש; בחירה שיטתית שלו תשתמש באימות בלבד.
עבדו לפי הסדר: נסחו את השאלה, זהו נתונים ויחידות, בחרו כלי שכבר נלמד, כתבו ציפייה, הריצו והסבירו תוצאה ומגבלה. במשימה שאינה מובנת חוזרים למושג או לדוגמה, ולא מחפשים שורת קוד להעתקה.
