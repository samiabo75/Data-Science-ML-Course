# מפגש 2 — Python for Data Science: היכרות עם Pandas

**עוגן:** המצגת 2.1 Python for DS; המחברות Pandas_01, Pandas_02, Pandas_03, PandasQ1, PandasQ2; דוגמת Penguin Dataset.

## מטרות
הכרת Series ו־DataFrame, טעינת CSV, head/info/describe, בחירת שורות ועמודות, סינון, מיון וערכים חסרים.

## מפת חומרי המקור
- Pandas_01.ipynb — Series, DataFrame, אינדקסים ובחירת נתונים.
- Pandas_02.ipynb — סינון וסיכומי נתונים.
- Pandas_03.ipynb — Diamonds, groupby וניתוח מתקדם (להמשך הפרק).
- PandasQ1.ipynb — משימות תרגול של בחירת עמודה, שורה ותא.
- PandasQ2.ipynb — טיפול מתקדם בערכים חסרים (להמשך הפרק).
- סמי_אבושח_penguin_dataset.py — הדגמת קריאה של קובץ Penguins וייבוא ספריות.

## רצף הוראה
1. פתיחה: Iris, מהו מאפיין, מהו סיווג ומהו Dataset.
2. קריאת CSV דרך קישור Raw והצגת הטבלה.
3. Series מול DataFrame, בחירה, תנאים ומיון.
4. תרגול Q1 על טבלת נתונים חדשה.
5. המשך: חסרים, Q2, groupby וניתוח Diamonds.

**חשוב:** תוכן המפגש והמחברות רחב מכדי ללמד את כולו בשיעור אחד; המיון הוא המלצה דידקטית המבוססת על החומרים.
