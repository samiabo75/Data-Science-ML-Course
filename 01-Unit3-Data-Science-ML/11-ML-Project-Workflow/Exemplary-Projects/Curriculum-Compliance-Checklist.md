# רשימת בדיקת איכות והתאמה ליחידה 3 — שלוש דוגמאות

**סוג המסמך:** מחוון עבודה פנימי למורה, **לא** מחוון משרד החינוך. יש להשוות למסמך הרשמי התקף לפני הכרזה על עמידה מלאה.

## בדיקת התוצר (בכל אחת משלוש המחברות)
| נושא | ראיה נדרשת במחברת | מצב בגרסת ההוראה |
|---|---|---|
| בעיה ושאלת חקר | ניסוח תחום, מטרה ומגבלה | שלד מוכן; מסקנה אחרי הרצה נדרשת |
| מאגר נתונים | קישור מקור, תיעוד רישוי, תאריך וגרסה | קישור מקור קיים; אימות רישוי נדרש |
| מינימום שורות/מאפיינים | מדידה אמיתית על הגרסה שהורדה | **טרם אומת** |
| Python ו־Pandas | טעינה, בחירת עמודות, תיאור וחסרים | קוד מוכן |
| EDA | גרפים מותאמים, מרכז ופיזור, פרשנות | גרפים ודוגמאות; נדרשת השלמת פרשנות |
| ניקוי וקידוד | החלטות מנומקות, טיפול בנתונים חסרים, קטגוריות | Pipeline מוכן |
| מניעת Leakage | Test מבודד, התאמת טרנספורמציות ל־Train | קוד מוכן לבדיקה |
| אלגוריתם בסיסי | KNN לסיווג / LinearRegression לרגרסיה | קוד מוכן |
| הערכה | Accuracy/F1/Confusion Matrix או R²/MAE | קוד מוכן, פלט טרם הופק |
| Validation | Cross Validation על Train | קוד מוכן |
| מסקנות | דיון בתוצאות, מגבלות, שיפור והוגנות | הנחיות כתיבה קיימות; תוכן אחרי הרצה |
| הצגת פרויקט | תשובות לשאלות בוחן והדגמת קוד | תרגול ומדריך; נדרש תרגול בעל פה |
| ריצה מלאה | Run all מתחילת הקובץ על נתונים אמיתיים | **טרם אומת** |

## בדיקות חובה לפני שימוש בכיתה
1. לפתוח כל מחברת מתוך GitHub ב־Google Colab.
2. לבצע **Run all**; לוודא כי KaggleHub וגישה ל־CSV החיצוני עובדים וששמות הקבצים תואמים.
3. לבדוק שבמאגר FTC עמודת `level` מוגדרת היטב ושאינה נגזרת ישירות מתוצאות שהוכנסו למאפיינים.
4. לבדוק שמספר השורות, טווחי הערכים, האיזון ורישוי המקור מתאימים לדרישות המחוון.
5. לשמור תמונת מצב/גרסה של הנתונים או מקור עם מזהה גרסה, בכפוף לרישיון.
6. להשלים דוגמת מסקנה המבוססת על **תוצאות ריצה אמיתיות**, לא על ציונים מומצאים.
7. להשוות כל דרישת מחוון רשמי לעדות בתוצר, לרבות הערכה חלופית והגנה בעל פה.

## שאלות בוחן משותפות
- מדוע בחרת את שאלת החקר? באיזה הקשר הנתונים נאספו?
- מהי יחידת התצפית ומהו משתנה המטרה?
- מה מקור ערכים חסרים וכיצד טיפלת בהם?
- מה הייתה החלוקה ל־Train/Test? מה הייתה מטרת CV?
- כיצד דאגת שהמידע של Test לא השפיע על התאמת המודל?
- למה בחרת במדד הזה? מהי תוצאת הבסיס?
- אילו מסקנות אי אפשר להסיק מהנתונים?
- מה היית משנה אם הייתה לך גישה לנתונים נוספים?

## הבחנה חשובה
ההצלחה של תלמיד אינה נמדדת במספר פקודות או במודל בעל הציון הגבוה ביותר, אלא ביכולת לבנות תהליך מדעי אמין, להוכיח שהקוד עובד, לנמק החלטות ולהציג מסקנות זהירות. שלוש הדוגמאות מספקות **תבנית הוראה**, לא אישור אוטומטי לציון 100.
