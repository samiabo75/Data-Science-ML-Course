# Used Cars — חיזוי מחיר רכב משומש

**גרסת הוראה מקורית ומתוקנת.** אין בה מחברות תלמידים, פרטי זיהוי או פלטים אישיים.

**חשוב:** הפרויקט אינו מאושר אוטומטית בציון 100. לפני שימוש מחייב יש לבדוק מחוון משרד החינוך התקף, רישוי המאגר, זמינות CSV ולהריץ את המחברת מתחילתה ועד סופה.

**עוגן:** מחברת Used-Cars שהועלתה

**שאלת חקר:** האם ניתן להעריך מחיר רכב Audi משומש על פי נתוני הרכב?

**מאגר:** [Kaggle – adityadesai13/used-car-dataset-ford-and-mercedes](https://www.kaggle.com/datasets/adityadesai13/used-car-dataset-ford-and-mercedes). המאגר **אינו מועתק** למאגר הציבורי ללא בדיקת רישוי.

## מטרות ומה התלמידים יתרגלו
| רכיב | תוצר |
|---|---|
| שאלת חקר ומילון נתונים | הגדרה מקצועית של X/y ומשתנים |
| Pandas ו־EDA | בדיקות איכות וגרפים מנומקים |
| הכנת נתונים | החלפה/קידוד ב־Pipeline ללא Leakage |
| מודל בסיסי והערכה | CV על Train, תוצאה על Test, מגבלות |
| דיווח וסיכום | מחברת עם מסקנות ורפלקציה |
