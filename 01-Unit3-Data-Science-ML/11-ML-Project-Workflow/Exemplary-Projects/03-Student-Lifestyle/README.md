# Student Lifestyle — חקר אורח חיים ורמת לחץ

**מחברת הוראה מקורית וללא פרטי תלמידים.** מבוססת על ניתוח של עבודת תלמיד, לא מפרסמת את עבודתו האישית.

**שאלת חקר:** האם מאפייני אורח חיים מאפשרים להעריך קטגוריות של רמת לחץ מדווחת?

**מקור:** [Kaggle Student Lifestyle Dataset](https://www.kaggle.com/datasets/steve1215rogg/student-lifestyle-dataset). הנתונים נדרשים להורדה בסביבת Colab, בכפוף לתנאי הרישוי.

## מה התלמידים יתרגלו?
Pandas, EDA, סטטיסטיקה, זיהוי חסרים, Train/Test, קידוד, Pipeline, KNN, F1, מטריצת בלבול, מסקנות והבחנה בין מתאם לסיבתיות.

- [מחברת מודרכת](./Guided-Exemplary-Project.ipynb)
- [תרגול עצמאי](./Independent-Project-Practice.ipynb)
- [מדריך למורה](./Didactic-Guide.md)

**סדר דידקטי מומלץ:** שאלת חקר (40 דק׳), EDA (80), הכנה (80), מודל והערכה (80), דיווח ורפלקציה (80) — 360 דקות בסך הכול.

**סטטוס:** נדרש אימות הרצה וגישה למאגר לפני שימוש; לא ניתן להבטיח עמידה מלאה במחוון ללא בדיקה סעיף־סעיף.
