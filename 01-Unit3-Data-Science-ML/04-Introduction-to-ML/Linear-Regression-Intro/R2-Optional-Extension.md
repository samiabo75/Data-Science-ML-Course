# הרחבת רשות — מדד R² ברגרסיה ליניארית

**שייכות:** יחידה 3 — מבוא לרגרסיה ליניארית. **סטטוס:** העשרה בלבד, לאחר התנסות ב־LinearRegression ו־predict.

## סיכום המצגת שהועלתה
המצגת *מדד R2 הרחבה רשות* מציגה את R² כמדד המבטא את שיעור השונות המוסברת מתוך השונות הכוללת. בדוגמה הגרפית מוצגות נקודות המתארות מדידות עלי פרח האירוס, קו רגרסיה אדום וקו אופקי ירוק של ממוצע ערכי המטרה.

- **SStot — שונות כללית (סכום ריבועי הסטיות מהממוצע):** כמה ערכי האמת שונים מהממוצע שלהם.
- **SSerr — שונות שאינה מוסברת (סכום ריבועי שגיאות החיזוי):** כמה החיזויים שונים מערכי האמת.
- **R² = 1 − SSerr / SStot**, כאשר SStot גדול מאפס.
- **R² = 1:** התאמה מלאה לנתונים שנבדקו.
- **R² = 0:** איכות החיזוי שווה לחיזוי קבוע לפי ממוצע ערכי האמת בקבוצת הבדיקה.
- **R² שלילי:** החיזויים פחות טובים מהשימוש בממוצע הזה.

במצגת נאמר שהערכים הם לרוב בין 0 ל־1, אך מודגש במפורש שגם ערכים שליליים אפשריים.
