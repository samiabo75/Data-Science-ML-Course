# KNN — מימוש עצמאי עם NumPy (מסלול Deep Learning)

**עוגן:** מצגת 5.3 *KNN with code implementation*, המחברת Knn_Iris_exercise2 והעבודה על Iris. הנושאים במקור כוללים Broadcasting, חישוב מרחקים, מיון שכנים ובחירת תגית שכיחה.

## מה התלמידים יתרגלו
- המרת DataFrame ל־NumPy.
- חיסור וקטור ממטריצה והבנת Broadcasting.
- חישוב מרחקי Euclidean ובחירת K שכנים קרובים.
- ספירת תוויות, ביצוע תחזית והשוואה למימוש sklearn.
- הבדלה בין מדד אימון ליכולת הכללה.

## דגשים והמלצות דידקטיות למורה — תוספת מקצועית

**לפני המימוש:** ודאו שליטה בסיסית ב־NumPy: shape, חיסור מערכים, axis, מיון ותוויות.

**סדר פיתוח:** דוגמה עם וקטור ושתי נקודות → Broadcasting של וקטור מול מטריצה → חישוב מרחקים → מיון אינדקסים → הצבעת רוב → השוואה ל־sklearn.

**טעויות נפוצות:** בלבול axis=0/1; מיון ערכי מרחק בלי לשמור אינדקסים מתאימים; ערבוב תגיות עם מאפיינים; אי־טיפול בתיקו; השוואה לא הוגנת בין מימושים עם סולמות שונים.

**התאמה לרמות:** למתקשים מימוש בשלבים עם הדפסת צורות מערכים; למצטיינים פתרון וקטורי ובדיקות יחידה פשוטות.

**הערכה:** דרשו מהתלמיד להסביר מה מחזיר כל שלב, לאתר שגיאה של אי־התאמת ממדים ולהשוות תוצאה על אותן דוגמאות למימוש ספרייה.

**חיבור לפרויקט:** תיעוד אלגוריתם, בדיקות וניתוח מורכבות חשובים יותר מהפעלת קוד שאינו מוסבר.
