# מדד R² — הרחבה מתמטית ברגרסיה ליניארית

**שייכות:** מסלול Deep Learning, פרק רגרסיה ליניארית. **עוגן:** המצגת *מדד R2 הרחבה רשות* (3 שקפים).

## סיכום צמוד למצגת
המצגת מציגה את R² כיחס השונות המוסברת לשונות הכוללת. התרשימים משתמשים בדוגמת רגרסיה לניבוי רוחב עלה אירוס מאורכו, ומבחינים בין הקו האופקי של ממוצע המשתנה המנובא לבין קו הרגרסיה והנקודות האמיתיות. שקף 2 מוקדש להבחנה בין שונות כללית, שונות מוסברת ושונות שאינה מוסברת.

נסמן ערך אמת ב־yᵢ, תחזית ב־ŷᵢ וממוצע ערכי האמת ב־ȳ.

- **SStot = Σ(yᵢ − ȳ)²** — סכום ריבועי הסטיות מהממוצע (כללי).
- **SSerr = Σ(yᵢ − ŷᵢ)²** — סכום ריבועי שגיאות החיזוי (לא מוסבר).
- **R² = 1 − SSerr/SStot**, בהנחה ש־SStot אינו אפס.
- ניתן לפרש את **SStot − SSerr** כרכיב מוסבר בהשוואה למנבא הממוצע. בפירוק סטטיסטי סטנדרטי לשונות מוסברת ולא מוסברת נדרשות הנחות מתאימות; אין להניח תמיד שסכום הריבועים המוסבר הסטנדרטי שווה להפרש זה בכל מודל או קבוצת בדיקה.

המצגת מדגישה: **1 — התאמה מלאה; 0 — לא טוב יותר מניבוי הממוצע; שלילי — גרוע מהניבוי לפי ממוצע.** היא מתארת ערכים שלרוב נמצאים בתחום 0–1, אך אינם מוגבלים לתחום זה.

## הדגמה עם Python
```python
import numpy as np
from sklearn.metrics import r2_score

y_true = np.array([1.0, 2.0, 3.0, 4.0])
y_pred = np.array([1.2, 1.8, 3.1, 3.9])
ss_tot = np.sum((y_true - np.mean(y_true))**2)
ss_err = np.sum((y_true - y_pred)**2)
print('SStot =', ss_tot)
print('SSerr =', ss_err)
print('R2 ידני =', 1 - ss_err / ss_tot)
print('R2 sklearn =', r2_score(y_true, y_pred))
```
