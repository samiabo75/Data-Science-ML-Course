# פייתון שימושי ליחידה 3 — ניתוח נתונים ולמידת מכונה

מיועד לתלמידים ללא רקע ב-Python. לומדים רק את השפה הדרושה לניתוח נתונים ולבניית מודל בסיסי.

## פרקי ההכנה בפייתון
- **01-Colab-Variables-and-Types** — היכרות עם Colab, משתנים, טיפוסים, הדפסה וחישובים
- **02-Lists-Dicts-and-Loops** — רשימות, מילונים, אינדקסים, תנאים ולולאות for
- **03-Functions-and-Math** — פונקציות עם פרמטרים וערכי החזרה, מרחק אוקלידי וחישובים
- **04-NumPy-Essentials** — מערכים, פעולות חשבון וחיתוך ב-NumPy
- **05-Pandas-Essentials** — קריאת CSV, DataFrame, סינון, מיון, קיבוץ, חסרים
- **06-Plotting-and-sklearn-Basics** — תרשימים בסיסיים וקריאה לפונקציות sklearn בפרויקט

הפרקים מציגים את הידע המוקדם והשימושי בפייתון בלבד, ואינם מחליפים את פרקי הסילבוס של התוכנית.
