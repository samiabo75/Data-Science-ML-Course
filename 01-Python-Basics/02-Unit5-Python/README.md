# פייתון שימושי ליחידה 5 — נושאי ליבה בבינה מלאכותית

הקדם המומלץ: יסודות Python של יחידה 3. הדגש כאן על המחשות מתמטיות וניתוח תוצאות; האלגוריתמים עצמם נלמדים ביחידה 5.

## פרקי ההכנה בפייתון
- **01-NumPy-Vectors-and-Distances** — וקטורים, חישובי L1/L2, מכפלה פנימית ודמיון קוסינוס
- **02-Statistics-and-Visualization** — ממוצע, חציון, שונות, סטיית תקן, התפלגויות ותרשימים
- **03-Pandas-and-Data-Scaling** — בדיקת נתונים, תקנון, נרמול והשוואת מאפיינים
- **04-sklearn-Experiments** — הפעלת KMeans, NearestCentroid ו-KNN, חלוקת נתונים, מדדים ו-Cross Validation

הפרקים מציגים את הידע המוקדם והשימושי בפייתון בלבד, ואינם מחליפים את פרקי הסילבוס של התוכנית.
