# פייתון שימושי להתמחות Deep Learning — 5 יחידות

נבנה על יסודות Python של יחידה 3. מוסיף מיומנויות תכנות ותשתיות הנדרשות לבניית מערכת למידה עמוקה ופרויקט גמר.

## פרקי ההכנה בפייתון
- **01-Python-Review-and-Functions** — חזרה ממוקדת על תנאים, לולאות, פונקציות, אוספים וכתיבת קוד קריא
- **02-Modules-Files-and-Packages** — import, מודולים, חבילות, pathlib, קריאה ושמירה של קבצים
- **03-OOP-Essentials** — מחלקות, עצמים, בנאים, פעולות והפרדת אחריות
- **04-NumPy-Arrays-and-Matrices** — מערכים רב-ממדיים, וקטורים, מטריצות, broadcasting
- **05-Images-and-Data-Pipelines** — עבודה עם תמונות, עיצוב גדלים, טעינת נתונים והכנת batches
- **06-Tensors-and-Training-Code** — טנזורים ומבנה קוד בסיסי לאימון מודל בספריית DL שתיבחר
- **07-Models-Evaluation-and-Saving** — חיזוי, גרפי אימון, שמירת מודל וטעינה מחדש
- **08-Project-Code-Organization** — פיצול קוד לקבצים, הגדרות, תיעוד וארגון יישום פרויקט

הפרקים מציגים את הידע המוקדם והשימושי בפייתון בלבד, ואינם מחליפים את פרקי הסילבוס של התוכנית.
