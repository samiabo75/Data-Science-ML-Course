# שיעור 12: מהחיים למתמטיקה וללמידת מכונה

## סיפור פתיחה
תלמידים מודדים זמני הגעה לאוטובוס ומחשבים ממוצע יומי. מדוע ממוצעי המדגמים יציבים יותר?

**שאלה לתלמידים לפני נוסחה:** מה ידוע, מה מחפשים ואילו נתונים דרושים?

## חישוב ידני מודרג
σ=12: SE(9)=12/√9=4; SE(36)=12/√36=2

**הנחיית מורה:** כתבו כל שלב על הלוח; הגדירו את הסימנים ואת היחידות, השוו לתחזית הכיתה ודרשו פירוש לתוצאה.

## מימוש Python ב־Google Colab
```python
import numpy as np
rng=np.random.default_rng(42)
for n in [9,36]:
 means=rng.exponential(12,size=(1000,n)).mean(axis=1)
 print(n,means.std())
```

**השוואה:** איזה חישוב ידני מתאים לכל פקודה, ומה ההבדל בין נתון, פעולה ופלט?
