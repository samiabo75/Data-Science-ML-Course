# פרומפט מצגת משודרג — שיעור 12

**שם המצגת:** שיעור 12 — מהסיפור האמיתי לנוסחה, לקוד ול־AI

צור מצגת לימודית בעברית רהוטה לכיתה י״א עם רקע בהיר ועיצוב נקי, בלי שגיאות כתיב. **פתח בסיפור ולא בהגדרה או בנוסחה:** תלמידים מודדים זמני הגעה לאוטובוס ומחשבים ממוצע יומי. מדוע ממוצעי המדגמים יציבים יותר?

סדר השקפים: (1) סיפור מעניין ואיור מעולם התלמידים, (2) השאלה שמעסיקה את הגיבור ואיסוף השערות, (3) הנתונים והמשתנים, (4) נוסחה והסבר כל סימן ויחידותיו, (5) חישוב ידני מפורט: σ=12: SE(9)=12/√9=4; SE(36)=12/√36=2, (6) איור/גרף מתמטי קריא עם צירים ותוויות, (7) Python ממומש בשלבים:

```python
import numpy as np
rng=np.random.default_rng(42)
for n in [9,36]:
 means=rng.exponential(12,size=(1000,n)).mean(axis=1)
 print(n,means.std())
```

(8) השוואה בין חישוב ידני לפלט המחשב, (9) **מדוע הנושא חשוב ללמידת מכונה:** משפט הגבול המרכזי עוסק בהתפלגות ממוצעי מדגמים, בתנאים המתאימים, ולא בנורמליות של נתוני המקור., (10) טעויות נפוצות, (11) בדיקת הבנה, (12) רמזים לקראת המעבדה העצמאית — ללא חשיפת הפתרון שלה.
