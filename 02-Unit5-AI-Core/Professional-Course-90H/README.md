## מצב אמיתי נכון ל־27.10.2026
- בתיקיות `Lesson-01` עד `Lesson-12` קיימות ערכות הוראה קודמות, המתוארות באינדקס [12 השיעורים](./START-HERE-12-LESSONS.md). לפי התיעוד הקיים מדובר ב־36 שעות מוצעות בלבד מתוך 90.
- ערכות מפגשים 1–3 המשודרגות שנוצרו בשיחה עדיין **לא פורסמו במאגר**. אין להציג קבצים אלה כמופיעים ב־main או כ־READY.
- החלוקה הראשונית לתחומים: מבוא 1, יסודות מתמטיים 9, סטטיסטיקה 26, בלתי מפוקחת 21, מפוקחת 25, הערכה 8 = 90. **כפוף לאימות מול הסילבוס הרשמי.**
- מספר מפגש במסלול המשודרג אינו בהכרח מספר שיעור במאגר הקודם או מספר מפגש בהשתלמות.
