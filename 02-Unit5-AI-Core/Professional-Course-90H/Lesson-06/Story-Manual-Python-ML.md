# שיעור 6: מהחיים למתמטיקה וללמידת מכונה

## סיפור פתיחה
לתלמידים ציונים 60,70,70,80,100. האם ציון 'טיפוסי' הוא 76 או 70?

**שאלה לתלמידים לפני נוסחה:** מה ידוע, מה מחפשים ואילו נתונים דרושים?

## חישוב ידני מודרג
ממוצע=(60+70+70+80+100)/5=76; חציון=70

**הנחיית מורה:** כתבו כל שלב על הלוח; הגדירו את הסימנים ואת היחידות, השוו לתחזית הכיתה ודרשו פירוש לתוצאה.

## מימוש Python ב־Google Colab

```python
import numpy as np
x=[60,70,70,80,100];print(np.mean(x),np.median(x))
```
