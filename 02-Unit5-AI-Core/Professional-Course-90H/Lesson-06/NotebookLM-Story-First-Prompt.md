# פרומפט מצגת משודרג — שיעור 6

**שם המצגת:** שיעור 6 — מהסיפור האמיתי לנוסחה, לקוד ול־AI

צור מצגת לימודית בעברית רהוטה לכיתה י״א עם רקע בהיר ועיצוב נקי, בלי שגיאות כתיב. **פתח בסיפור ולא בהגדרה או בנוסחה:** לתלמידים ציונים 60,70,70,80,100. האם ציון 'טיפוסי' הוא 76 או 70?

סדר השקפים: (1) סיפור מעניין ואיור מעולם התלמידים, (2) השאלה שמעסיקה את הגיבור ואיסוף השערות, (3) הנתונים והמשתנים, (4) נוסחה והסבר כל סימן ויחידותיו, (5) חישוב ידני מפורט: ממוצע=(60+70+70+80+100)/5=76; חציון=70, (6) איור/גרף מתמטי קריא עם צירים ותוויות, (7) Python ממומש בשלבים:

```python
import numpy as np
x=[60,70,70,80,100];print(np.mean(x),np.median(x))
```

(8) השוואה בין חישוב ידני לפלט המחשב, (9) **מדוע הנושא חשוב ללמידת מכונה:** EDA בוחן מרכז הנתונים לפני אימון; הממוצע רגיש לקיצוניים., (10) טעויות נפוצות, (11) בדיקת הבנה, (12) רמזים לקראת המעבדה העצמאית — ללא חשיפת הפתרון שלה.
