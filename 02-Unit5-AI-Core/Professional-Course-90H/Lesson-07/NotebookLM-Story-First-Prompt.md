# פרומפט מצגת משודרג — שיעור 7

**שם המצגת:** שיעור 7 — מהסיפור האמיתי לנוסחה, לקוד ול־AI

צור מצגת לימודית בעברית רהוטה לכיתה י״א עם רקע בהיר ועיצוב נקי, בלי שגיאות כתיב. **פתח בסיפור ולא בהגדרה או בנוסחה:** תלמיד מחכה בקפיטריה 30 דקות בעוד רוב התלמידים מחכים 3–10 דקות. למחוק את הנתון?

סדר השקפים: (1) סיפור מעניין ואיור מעולם התלמידים, (2) השאלה שמעסיקה את הגיבור ואיסוף השערות, (3) הנתונים והמשתנים, (4) נוסחה והסבר כל סימן ויחידותיו, (5) חישוב ידני מפורט: אם Q₁=4,Q₃=10: IQR=6 וגבול חריג עליון=19, (6) איור/גרף מתמטי קריא עם צירים ותוויות, (7) Python ממומש בשלבים:

```python
import numpy as np
x=[3,4,4,5,6,8,10,30];q1,q3=np.percentile(x,[25,75]);print(q1,q3,q3+1.5*(q3-q1))
```

(8) השוואה בין חישוב ידני לפלט המחשב, (9) **מדוע הנושא חשוב ללמידת מכונה:** בדיקות חריגים עוזרות להכנת נתונים; יש לבחון את הסיבה ולא למחוק אוטומטית., (10) טעויות נפוצות, (11) בדיקת הבנה, (12) רמזים לקראת המעבדה העצמאית — ללא חשיפת הפתרון שלה.
