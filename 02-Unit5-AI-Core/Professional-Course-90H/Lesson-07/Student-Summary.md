# שיעור 7 — רבעונים וטווח בין־רבעוני — סיכום לתלמיד

## למה לומדים את זה?
האם זמן המתנה חריג ביחס לשאר הלקוחות? במערכות בינה מלאכותית מתרגמים בעיה לנתונים, מבצעים פעולה מתמטית ומפרשים תוצאה.

## מטרת הלמידה
לפרש Q1,Q2,Q3, IQR וגבולות חריגים.

## המושג המרכזי
IQR=Q3−Q1; גבולות: Q1−1.5IQR, Q3+1.5IQR (כלל תיאורי).

## דוגמה מודרכת
פתחו את המחברת `Guided.ipynb`. בצעו תחילה הערכה ידנית של התוצאה, אחר כך הריצו את הקוד. שימו לב: שמות של פונקציות אינם תחליף להבנת משמעות החישוב.

```python
import numpy as np
x=np.array([2,3,4,5,6,7,8,20])
q1,q2,q3=np.percentile(x,[25,50,75])
iqr=q3-q1
print('רבעונים',q1,q2,q3,'גבולות',q1-1.5*iqr,q3+1.5*iqr)
```

## כיצד מסבירים תוצאה מתמטית?
1. מציינים מה הם הנתונים והיחידות.  
2. מגדירים איזו שאלה בודקים ואיזו נוסחה מתאימה.  
3. כותבים תוצאה ומסבירים אותה במילים.  
4. בודקים אם ההנחות מתקיימות והאם קיימת מגבלה.

## משימה עצמאית
חשב רבעונים ו־IQR לערכים [3,4,4,5,6,8,10,30]. הדגש ששיטות חישוב הרבעונים עשויות להיות שונות.
