# פתרון מורה מורחב — שיעור 1

## ההקשר שמניע את הלמידה
מערכת החוגים בבית הספר רוצה ללמוד מה מוביל תלמידים לבחור ברובוטיקה.

## חישוב מתמטי ופתרון מלא לדוגמת הפתיחה
X=[[80,3],[90,5],[70,2]] → 3 דוגמאות × 2 מאפיינים

על המורה לפרש כל רכיב ולהציג את ההצבה ולא רק את השורה הסופית. יש לוודא מהו הקלט, אילו הנחות נדרשות ומה מייצגת התוצאה. בהמשך השיעור משווים לחשבון של תלמידים לפני הפעלת הקוד.

## פתרון Python להדגמת הפתיחה
```python
features=[[80,3],[90,5],[70,2]]
print(len(features),len(features[0]))
```

## ניתוח מקצועי לתלמיד
X מכיל מאפייני תלמידים; היעד y (בחירת חוג) נלמד בנפרד.

תשובה טובה כוללת: זיהוי משתנים, נוסחה רלוונטית, הצבה נכונה, חישוב, הסבר תוצאה, השוואה לקוד והבחנה במגבלה. בדיקה בעל־פה: 'מה ישתנה אם נשנה ערך אחד?' ו'מה אומר המספר בהקשר לסיפור?'.
