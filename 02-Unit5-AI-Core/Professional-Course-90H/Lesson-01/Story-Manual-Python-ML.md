# שיעור 1: מהחיים למתמטיקה וללמידת מכונה

## סיפור פתיחה
מערכת החוגים בבית הספר רוצה ללמוד מה מוביל תלמידים לבחור ברובוטיקה.

**שאלה לתלמידים לפני נוסחה:** מה ידוע, מה מחפשים ואילו נתונים דרושים?

## חישוב ידני מודרג
X=[[80,3],[90,5],[70,2]] → 3 דוגמאות × 2 מאפיינים

**הנחיית מורה:** כתבו כל שלב על הלוח; הגדירו את הסימנים ואת היחידות, השוו לתחזית הכיתה ודרשו פירוש לתוצאה.

## מימוש Python ב־Google Colab
```python
features=[[80,3],[90,5],[70,2]]
print(len(features),len(features[0]))
```

**השוואה:** איזה חישוב ידני מתאים לכל פקודה, ומה ההבדל בין נתון, פעולה ופלט?

## הקשר ללמידת מכונה
X מכיל מאפייני תלמידים; היעד y (בחירת חוג) נלמד בנפרד.

## המחשה גרפית
פתחו את `Mathematical-Illustration.svg` והסבירו מה הגרף ממחיש. יש להבחין בין איור סכמטי לבין גרף מדויק שמחושב מהנתונים; לפני הצגה בתור גרף כמותי יש לבדוק צירים, סולמות, ויחידות.

## שאלות בדיקת הבנה ופתרון מנחה
1. **מה שואלים?** לזהות את השאלה מתוך הסיפור ואת הנתונים הדרושים.
2. **למה זו הנוסחה?** להסביר במילים את הפעולה ואת משמעות המשתנים.
3. **מה הפתרון הידני?** X=[[80,3],[90,5],[70,2]] → 3 דוגמאות × 2 מאפיינים
4. **איפה זה בקוד?** לאתר את פעולת החישוב בקוד ולהדפיס תוצאה.
5. **מה הקשר ל־AI?** X מכיל מאפייני תלמידים; היעד y (בחירת חוג) נלמד בנפרד.
6. **הרחבה:** לשנות נתון אחד, לחשב מחדש ולהסביר מה השתנה.

**רמות תמיכה:** מתחילים — 2–3 נתונים בלבד; רמה רגילה — כל הדוגמה; מצטיינים — שינוי תנאי, ניסוח מגבלה והסבר התלות בתוצאה.

**הערת דיוק:** הנתונים דידקטיים, לא תוצאות מחקר. איור וסימולציה אינם מוכיחים לבדם טענה כללית.
