# פרומפט מצגת משודרג — שיעור 1

**שם המצגת:** שיעור 1 — מהסיפור האמיתי לנוסחה, לקוד ול־AI

צור מצגת לימודית בעברית רהוטה לכיתה י״א עם רקע בהיר ועיצוב נקי, בלי שגיאות כתיב. **פתח בסיפור ולא בהגדרה או בנוסחה:** מערכת החוגים בבית הספר רוצה ללמוד מה מוביל תלמידים לבחור ברובוטיקה.

סדר השקפים: (1) סיפור מעניין ואיור מעולם התלמידים, (2) השאלה שמעסיקה את הגיבור ואיסוף השערות, (3) הנתונים והמשתנים, (4) נוסחה והסבר כל סימן ויחידותיו, (5) חישוב ידני מפורט: X=[[80,3],[90,5],[70,2]] → 3 דוגמאות × 2 מאפיינים, (6) איור/גרף מתמטי קריא עם צירים ותוויות, (7) Python ממומש בשלבים:

```python
features=[[80,3],[90,5],[70,2]]
print(len(features),len(features[0]))
```

(8) השוואה בין חישוב ידני לפלט המחשב, (9) **מדוע הנושא חשוב ללמידת מכונה:** X מכיל מאפייני תלמידים; היעד y (בחירת חוג) נלמד בנפרד., (10) טעויות נפוצות, (11) בדיקת הבנה, (12) רמזים לקראת המעבדה העצמאית — ללא חשיפת הפתרון שלה.
