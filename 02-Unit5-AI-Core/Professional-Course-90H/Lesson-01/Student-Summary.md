# שיעור 1 — מבוא לבינה מלאכותית ולמידת מכונה — סיכום לתלמיד

## למה לומדים את זה?
איך מערכת ממליצה על סרט מתאים? במערכות בינה מלאכותית מתרגמים בעיה לנתונים, מבצעים פעולה מתמטית ומפרשים תוצאה.

## מטרת הלמידה
להבחין בין כללים ידניים ללמידה מנתונים.

## המושג המרכזי
רשומת תלמיד היא וקטור מאפיינים; מאגר הוא מטריצה.

## דוגמה מודרכת
פתחו את המחברת `Guided.ipynb`. בצעו תחילה הערכה ידנית של התוצאה, אחר כך הריצו את הקוד. שימו לב: שמות של פונקציות אינם תחליף להבנת משמעות החישוב.

```python
features = [[2, 4], [4, 5], [5, 3]]
print('מספר רשומות:', len(features))
print('מאפיינים ברשומה:', len(features[0]))
```

## כיצד מסבירים תוצאה מתמטית?
1. מציינים מה הם הנתונים והיחידות.  
2. מגדירים איזו שאלה בודקים ואיזו נוסחה מתאימה.  
3. כותבים תוצאה ומסבירים אותה במילים.  
4. בודקים אם ההנחות מתקיימות והאם קיימת מגבלה.

## משימה עצמאית
צור רשימה של 4 רשומות, לכל רשומה 3 מאפיינים. הדפס מספר רשומות ומאפיינים; הסבר קלט ופלט.
