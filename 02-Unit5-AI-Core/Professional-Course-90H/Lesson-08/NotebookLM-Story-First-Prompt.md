**שם המצגת:** שיעור 8 — מהסיפור האמיתי לנוסחה, לקוד ול־AI

צור מצגת לימודית בעברית רהוטה לכיתה י״א עם רקע בהיר ועיצוב נקי, בלי שגיאות כתיב. **פתח בסיפור ולא בהגדרה או בנוסחה:** שתי כיתות קיבלו ממוצע 80, אבל באחת הציונים מפוזרים יותר.

סדר השקפים: (1) סיפור מעניין ואיור מעולם התלמידים, (2) השאלה שמעסיקה את הגיבור ואיסוף השערות, (3) הנתונים והמשתנים, (4) נוסחה והסבר כל סימן ויחידותיו, (5) חישוב ידני מפורט: 70,80,90: μ=80, σ²=(100+0+100)/3≈66.67, σ≈8.165, (6) איור/גרף מתמטי קריא עם צירים ותוויות, (7) Python ממומש בשלבים:

```python
import numpy as np
x=[70,80,90];print(np.mean(x),np.var(x),np.std(x))
```

(8) השוואה בין חישוב ידני לפלט המחשב, (9) **מדוע הנושא חשוב ללמידת מכונה:** StandardScaler נשען על ממוצע וסטיית תקן המחושבים מנתוני האימון בלבד., (10) טעויות נפוצות, (11) בדיקת הבנה, (12) רמזים לקראת המעבדה העצמאית — ללא חשיפת הפתרון שלה.
