# שיעור 8 — שונות וסטיית תקן — סיכום לתלמיד

## למה לומדים את זה?
לשתי כיתות אותו ממוצע: האם פיזור הציונים דומה? במערכות בינה מלאכותית מתרגמים בעיה לנתונים, מבצעים פעולה מתמטית ומפרשים תוצאה.

## מטרת הלמידה
לחשב שונות וסטיית תקן ולהבחין בין אוכלוסייה למדגם.

## המושג המרכזי
שונות אוכלוסייה מחלקים ב־N, אומדן שונות מדגם ב־n−1.

## דוגמה מודרכת
פתחו את המחברת `Guided.ipynb`. בצעו תחילה הערכה ידנית של התוצאה, אחר כך הריצו את הקוד. שימו לב: שמות של פונקציות אינם תחליף להבנת משמעות החישוב.

```python
import numpy as np
x=np.array([60,70,80,90,100])
print('ממוצע',np.mean(x))
print('שונות אוכלוסייה',np.var(x,ddof=0))
print('שונות מדגם',np.var(x,ddof=1))
print('סטיית תקן',np.std(x,ddof=0))
```

## כיצד מסבירים תוצאה מתמטית?
1. מציינים מה הם הנתונים והיחידות.  
2. מגדירים איזו שאלה בודקים ואיזו נוסחה מתאימה.  
3. כותבים תוצאה ומסבירים אותה במילים.  
4. בודקים אם ההנחות מתקיימות והאם קיימת מגבלה.
