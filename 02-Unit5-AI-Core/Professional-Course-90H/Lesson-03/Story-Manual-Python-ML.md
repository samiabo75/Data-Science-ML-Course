# שיעור 3: מהחיים למתמטיקה וללמידת מכונה

## סיפור פתיחה
דמות במשחק מקבלת ניקוד ממהירות וכוח: איך מחשבים דירוג בעזרת משקולות?

**שאלה לתלמידים לפני נוסחה:** מה ידוע, מה מחפשים ואילו נתונים דרושים?

## חישוב ידני מודרג
x=(3,4),w=(2,1): w·x=2·3+1·4=10; ‖x‖=5

**הנחיית מורה:** כתבו כל שלב על הלוח; הגדירו את הסימנים ואת היחידות, השוו לתחזית הכיתה ודרשו פירוש לתוצאה.

## מימוש Python ב־Google Colab
```python
import numpy as np
x=np.array([3,4]);w=np.array([2,1]);print(np.dot(w,x),np.linalg.norm(x))
```

**השוואה:** איזה חישוב ידני מתאים לכל פקודה, ומה ההבדל בין נתון, פעולה ופלט?

## הקשר ללמידת מכונה
w·x+b הוא רכיב של מודל ליניארי ונוירון; המשקולות נלמדות באימון.
