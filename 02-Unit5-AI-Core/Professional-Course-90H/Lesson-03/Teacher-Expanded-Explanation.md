## ההקשר שמניע את הלמידה
דמות במשחק מקבלת ניקוד ממהירות וכוח: איך מחשבים דירוג בעזרת משקולות?

## חישוב מתמטי ופתרון מלא לדוגמת הפתיחה
x=(3,4),w=(2,1): w·x=2·3+1·4=10; ‖x‖=5

על המורה לפרש כל רכיב ולהציג את ההצבה ולא רק את השורה הסופית. יש לוודא מהו הקלט, אילו הנחות נדרשות ומה מייצגת התוצאה. בהמשך השיעור משווים לחשבון של תלמידים לפני הפעלת הקוד.

## פתרון Python להדגמת הפתיחה
```python
import numpy as np
x=np.array([3,4]);w=np.array([2,1]);print(np.dot(w,x),np.linalg.norm(x))
```

## ניתוח מקצועי לתלמיד
w·x+b הוא רכיב של מודל ליניארי ונוירון; המשקולות נלמדות באימון.
