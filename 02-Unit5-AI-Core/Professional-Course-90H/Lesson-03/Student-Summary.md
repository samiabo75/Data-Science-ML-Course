## המושג המרכזי
u·v=Σuᵢvᵢ; ||u||₂=√Σuᵢ².

## דוגמה מודרכת
פתחו את המחברת `Guided.ipynb`. בצעו תחילה הערכה ידנית של התוצאה, אחר כך הריצו את הקוד. שימו לב: שמות של פונקציות אינם תחליף להבנת משמעות החישוב.

```python
import numpy as np
u = np.array([3, 4])
v = np.array([2, 1])
print('חיבור:', u + v)
print('מכפלה פנימית:', np.dot(u, v))
print('נורמה:', np.linalg.norm(u))
```
