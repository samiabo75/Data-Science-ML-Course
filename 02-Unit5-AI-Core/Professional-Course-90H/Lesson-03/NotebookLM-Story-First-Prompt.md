# פרומפט מצגת משודרג — שיעור 3

**שם המצגת:** שיעור 3 — מהסיפור האמיתי לנוסחה, לקוד ול־AI

צור מצגת לימודית בעברית רהוטה לכיתה י״א עם רקע בהיר ועיצוב נקי, בלי שגיאות כתיב. **פתח בסיפור ולא בהגדרה או בנוסחה:** דמות במשחק מקבלת ניקוד ממהירות וכוח: איך מחשבים דירוג בעזרת משקולות?

סדר השקפים: (1) סיפור מעניין ואיור מעולם התלמידים, (2) השאלה שמעסיקה את הגיבור ואיסוף השערות, (3) הנתונים והמשתנים, (4) נוסחה והסבר כל סימן ויחידותיו, (5) חישוב ידני מפורט: x=(3,4),w=(2,1): w·x=2·3+1·4=10; ‖x‖=5, (6) איור/גרף מתמטי קריא עם צירים ותוויות, (7) Python ממומש בשלבים:

```python
import numpy as np
x=np.array([3,4]);w=np.array([2,1]);print(np.dot(w,x),np.linalg.norm(x))
```

(8) השוואה בין חישוב ידני לפלט המחשב, (9) **מדוע הנושא חשוב ללמידת מכונה:** w·x+b הוא רכיב של מודל ליניארי ונוירון; המשקולות נלמדות באימון., (10) טעויות נפוצות, (11) בדיקת הבנה, (12) רמזים לקראת המעבדה העצמאית — ללא חשיפת הפתרון שלה.
