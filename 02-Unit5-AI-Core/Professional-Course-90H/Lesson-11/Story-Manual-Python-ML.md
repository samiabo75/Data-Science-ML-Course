# שיעור 11: מהחיים למתמטיקה וללמידת מכונה

## סיפור פתיחה
במשחק מהירות תגובה הממוצע 100 מילישניות וסטיית התקן 15. מה הסיכוי לתוצאה בין 85 ל־115?

**שאלה לתלמידים לפני נוסחה:** מה ידוע, מה מחפשים ואילו נתונים דרושים?

## חישוב ידני מודרג
z(85)=−1; z(115)=1; P(85<X<115)≈0.6827

**הנחיית מורה:** כתבו כל שלב על הלוח; הגדירו את הסימנים ואת היחידות, השוו לתחזית הכיתה ודרשו פירוש לתוצאה.

## מימוש Python ב־Google Colab
```python
from scipy.stats import norm
print(norm.cdf(115,100,15)-norm.cdf(85,100,15))
```

**השוואה:** איזה חישוב ידני מתאים לכל פקודה, ומה ההבדל בין נתון, פעולה ופלט?

## הקשר ללמידת מכונה
הסתברות היא שטח; P(X=a)=0 ברציף בעל צפיפות; תקנון לא מבטיח נורמליות.
