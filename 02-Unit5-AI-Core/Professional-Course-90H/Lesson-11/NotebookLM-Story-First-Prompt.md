# פרומפט מצגת משודרג — שיעור 11

**שם המצגת:** שיעור 11 — מהסיפור האמיתי לנוסחה, לקוד ול־AI

צור מצגת לימודית בעברית רהוטה לכיתה י״א עם רקע בהיר ועיצוב נקי, בלי שגיאות כתיב. **פתח בסיפור ולא בהגדרה או בנוסחה:** במשחק מהירות תגובה הממוצע 100 מילישניות וסטיית התקן 15. מה הסיכוי לתוצאה בין 85 ל־115?

סדר השקפים: (1) סיפור מעניין ואיור מעולם התלמידים, (2) השאלה שמעסיקה את הגיבור ואיסוף השערות, (3) הנתונים והמשתנים, (4) נוסחה והסבר כל סימן ויחידותיו, (5) חישוב ידני מפורט: z(85)=−1; z(115)=1; P(85<X<115)≈0.6827, (6) איור/גרף מתמטי קריא עם צירים ותוויות, (7) Python ממומש בשלבים:

```python
from scipy.stats import norm
print(norm.cdf(115,100,15)-norm.cdf(85,100,15))
```

(8) השוואה בין חישוב ידני לפלט המחשב, (9) **מדוע הנושא חשוב ללמידת מכונה:** הסתברות היא שטח; P(X=a)=0 ברציף בעל צפיפות; תקנון לא מבטיח נורמליות., (10) טעויות נפוצות, (11) בדיקת הבנה, (12) רמזים לקראת המעבדה העצמאית — ללא חשיפת הפתרון שלה.
