# שיעור 5: מהחיים למתמטיקה וללמידת מכונה

## סיפור פתיחה
אפליקציית סרטים רוצה להמליץ על סרט שמתאים להעדפות תלמיד, לא רק לדירוג הגבוה ביותר.

**שאלה לתלמידים לפני נוסחה:** מה ידוע, מה מחפשים ואילו נתונים דרושים?

## חישוב ידני מודרג
u=(1,0),v=(1,1): cosθ=1/(1·√2)≈0.707

**הנחיית מורה:** כתבו כל שלב על הלוח; הגדירו את הסימנים ואת היחידות, השוו לתחזית הכיתה ודרשו פירוש לתוצאה.

## מימוש Python ב־Google Colab
```python
import numpy as np
u=np.array([1.,0.]);v=np.array([1.,1.]);print(np.dot(u,v)/(np.linalg.norm(u)*np.linalg.norm(v)))
```

**השוואה:** איזה חישוב ידני מתאים לכל פקודה, ומה ההבדל בין נתון, פעולה ופלט?
