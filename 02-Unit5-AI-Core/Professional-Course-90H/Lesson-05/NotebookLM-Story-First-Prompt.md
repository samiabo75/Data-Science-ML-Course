**שם המצגת:** שיעור 5 — מהסיפור האמיתי לנוסחה, לקוד ול־AI

צור מצגת לימודית בעברית רהוטה לכיתה י״א עם רקע בהיר ועיצוב נקי, בלי שגיאות כתיב. **פתח בסיפור ולא בהגדרה או בנוסחה:** אפליקציית סרטים רוצה להמליץ על סרט שמתאים להעדפות תלמיד, לא רק לדירוג הגבוה ביותר.

סדר השקפים: (1) סיפור מעניין ואיור מעולם התלמידים, (2) השאלה שמעסיקה את הגיבור ואיסוף השערות, (3) הנתונים והמשתנים, (4) נוסחה והסבר כל סימן ויחידותיו, (5) חישוב ידני מפורט: u=(1,0),v=(1,1): cosθ=1/(1·√2)≈0.707, (6) איור/גרף מתמטי קריא עם צירים ותוויות, (7) Python ממומש בשלבים:

```python
import numpy as np
u=np.array([1.,0.]);v=np.array([1.,1.]);print(np.dot(u,v)/(np.linalg.norm(u)*np.linalg.norm(v)))
```
