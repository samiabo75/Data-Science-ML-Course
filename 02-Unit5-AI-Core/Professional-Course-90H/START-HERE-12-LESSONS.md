## שיעור 07 — רבעונים ו־IQR

**סיפור פתיחה:** תלמיד חיכה לקפיטריה 30 דקות. האם זה זמן חריג?

**נוסחה:** IQR=Q₃−Q₁ ; גבול עליון=Q₃+1.5×IQR

### חישוב ידני — שלב אחר שלב
- 1. להדגמה נתונים ממוינים: 2,4,4,5,6,8,10,30.
- 2. בשיטת חצאי המדגם: Q₁=(4+4)/2=4.
- 3. Q₃=(8+10)/2=9.
- 4. IQR=9−4=5.
- 5. גבול עליון=9+1.5×5=16.5.
- 6. זמן 30 מסומן כחריג לבדיקה, לא למחיקה אוטומטית.

### קוד Python — משחזר את החישוב
```python
import numpy as np
x=np.array([2,4,4,5,6,8,10,30])
# שיטת חצאי המדגם, כדי לשחזר חישוב ידני
q1=np.median(x[:4]);q3=np.median(x[4:])
print(q1,q3,q3+1.5*(q3-q1))
```

**קשר ללמידת מכונה:** EDA מזהה ערכים חשודים; החלטת טיפול בחריגים צריכה הסבר והפרדה בין Train ו־Test.

**גרף/המחשה:** תרשים קופסה עם סימון 30; להסביר שקיימות שיטות רבעונים שונות.

## שיעור 10 — התפלגות נורמלית וסימולטור Plinko

**סיפור פתיחה:** מדוע כאשר מפילים אלפי כדורים רבים מהם נוחתים באמצע?

**נוסחה:** P(K=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ

### חישוב ידני — שלב אחר שלב
- 1. ארבע פניות בלתי תלויות, p=0.5.
- 2. רוצים בדיוק שתי פניות ימינה.
- 3. מספר הסדרים: C(4,2)=4!/(2!2!)=6.
- 4. הסתברות לכל סדר: (1/2)^4=1/16.
- 5. לכן P(K=2)=6/16=0.375.

### קוד Python — משחזר את החישוב
```python
from math import comb
n=4;k=2;p=0.5
print(comb(n,k)*p**k*(1-p)**(n-k))
```

**קשר ללמידת מכונה:** הסתברויות תומכות בפרשנות תהליכים אקראיים. Plinko מייצג תוצאה בדידה, גם אם צורת העמודות מתקרבת לפעמון.

**גרף/המחשה:** עמודות עבור k=0…4, הגובה המרכזי 6/16.

## שיעור 11 — Z, צפיפות והסתברות

**סיפור פתיחה:** מה הסיכוי שזמן התגובה במשחק יהיה בין 85 ל־115 מילישניות?

**נוסחה:** Z=(X−μ)/σ ; P(a<X<b)=F(b)−F(a)

### חישוב ידני — שלב אחר שלב
- 1. נניח X~N(100,15²).
- 2. בקצה התחתון Z=(85−100)/15=−1.
- 3. בקצה העליון Z=(115−100)/15=1.
- 4. בטבלת נורמלית תקנית Φ(1)≈0.8413 ו־Φ(−1)≈0.1587.
- 5. הפרש: 0.8413−0.1587≈0.6826 (ערך מדויק יותר ≈0.6827).
- 6. ההסתברות לערך מדויק היא 0 עבור משתנה בעל צפיפות.

### קוד Python — משחזר את החישוב
```python
from scipy.stats import norm
p=norm.cdf(115,loc=100,scale=15)-norm.cdf(85,loc=100,scale=15)
print(round(p,4))
```

**קשר ללמידת מכונה:** הסתברות לקטע היא שטח, לא גובה PDF בנקודה. תקנון לבדו אינו מוכיח נורמליות.

**גרף/המחשה:** עקומת צפיפות והשטח המוצל בין Z=−1 ל־Z=1.

## שיעור 12 — משפט הגבול המרכזי

**סיפור פתיחה:** מדוע ממוצעי זמני המתנה לאוטובוס יציבים יותר מזמני המתנה בודדים?

**נוסחה:** SE(X̄)=σ/√n

### חישוב ידני — שלב אחר שלב
- 1. נניח באוכלוסייה σ=12 דקות.
- 2. למדגם בגודל n=9: SE=12/√9=12/3=4.
- 3. למדגם בגודל n=36: SE=12/√36=12/6=2.
- 4. פי 4 בגודל המדגם מקטין את שגיאת התקן פי 2; ממוצעי המדגמים מתרכזים יותר סביב μ.

### קוד Python — משחזר את החישוב
```python
import numpy as np
rng=np.random.default_rng(42)
for n in [9,36]:
 m=rng.exponential(scale=12,size=(1000,n)).mean(axis=1)
 print(n,round(m.std(ddof=0),2))
```

**קשר ללמידת מכונה:** בתנאי CLT המקובלים, התפלגות ממוצעי המדגמים נעשית בקירוב נורמלית; ההתפלגות המקורית אינה משתנה.

**גרף/המחשה:** שלוש היסטוגרמות: מדידות מקור, ממוצעים n=9, ממוצעים n=36.

**שאלת הבנה למורה:** מה מייצגת התוצאה, ומה ישתנה אם נחליף נתון אחד? הסבירו לפני הרצת הקוד.
