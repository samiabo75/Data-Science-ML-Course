# שיעור 2: מהחיים למתמטיקה וללמידת מכונה

## סיפור פתיחה
באפליקציית הספורט של תלמידי הכיתה נמדדו זמני אימון 20,30,40 דקות.

**שאלה לתלמידים לפני נוסחה:** מה ידוע, מה מחפשים ואילו נתונים דרושים?

## חישוב ידני מודרג
x̄=(20+30+40)/3=30

**הנחיית מורה:** כתבו כל שלב על הלוח; הגדירו את הסימנים ואת היחידות, השוו לתחזית הכיתה ודרשו פירוש לתוצאה.

## מימוש Python ב־Google Colab
```python
import numpy as np
x=np.array([20,30,40]);print(np.mean(x))
```

**השוואה:** איזה חישוב ידני מתאים לכל פקודה, ומה ההבדל בין נתון, פעולה ופלט?

ממוצע הוא תיאור נתונים וגם תחזית בסיס; לבדו אינו מודל מורכב.
