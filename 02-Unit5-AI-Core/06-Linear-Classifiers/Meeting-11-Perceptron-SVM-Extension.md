# פרספטרון ו־SVM — העמקה ביחידה 5

## עוגן
מצגת Percepton and SVM: מודל החלטה `z=w·x+b`, אימון בעדכון משקולות, קו הפרדה, SVM ליניארי, שוליים מקסימליים, C, kernel ליניארי/פולינומי/RBF/סיגמואיד ו־GridSearchCV.

## מטרות
1. לבצע עקיבה מתמטית מלאה אחר עדכוני פרספטרון.
2. לגזור קו הפרדה ב־2D ולקבוע סימן החלטה לפי צד הקו.
3. לפרש שוליים רחבים ב־SVM ואת השפעת C.
4. להסביר את הרעיון של Kernel ללא חישוב הנוסחה המלאה.
5. להבחין בין אימון, Validation ובדיקה בהשוואת פרמטרים.

## מה התלמידים יתרגלו?
| פעילות | תוצר |
|---|---|
| ארבע דוגמאות עיר/יער | טבלת עדכון ומשקולות |
| שינוי ב־w1,w2,b | משוואת קו ושרטוט |
| השוואת C קטן לגדול | הסבר סיכון Overfitting |
| Kernel ליניארי מול RBF | פרשנות גבולות החלטה |
| GridSearchCV על Train | בחירת מודל מנומקת |

## דגשים למורה
- אין להציג kernel כטריק המבטיח שיפור דיוק בכל Dataset.
- פרספטרון פשוט עלול לא להתכנס בנתונים שאינם ניתנים להפרדה ליניארית; יש להגביל מספר אפוקים בתוכניות מחשב.
- כשבוחנים את C, אין לבחור אותו לפי Test; משתמשים ב־CV על Train.
- פתרון דף העבודה המצורף כולל אי־התאמות בשורות המאוחרות של העקיבה; בדקו מחדש עם הכלל `z>0`.
- לתלמידים מתקשים התחילו בשתי נקודות, ולמצטיינים השוו גרפים של שוליים עם נתונים חופפים.
