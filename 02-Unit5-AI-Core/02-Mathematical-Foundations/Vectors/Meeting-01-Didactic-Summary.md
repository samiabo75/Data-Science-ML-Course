# מפגש 1 — פרק 1.1: וקטורים ב־Rⁿ

## סיכום נאמן למצגת פרק 1.1
המצגת **וקטורים ב־Rⁿ** מציגה רשומה כווקטור, Dataset כמטריצה, ודמיון ומרחק כפעולות על וקטורים. בדוגמת Student Profile נמדדות שש תכונות: מתמטיקה, הומניסטיקה, ספורט, מוזיקה, שעות שינה ושעות פעילות חברתית.

## מושגים ונוסחאות
- וקטור ב־Rⁿ כולל n רכיבים ממשיים.
- חיבור וחיסור וקטורים: (x±y)ᵢ=xᵢ±yᵢ.
- הכפלה בסקלר: (αx)ᵢ=αxᵢ.
- מכפלה רכיבית: וקטור המכפלות xᵢyᵢ; **מכפלה פנימית:** x·y=Σxᵢyᵢ, שהיא סקלר.
- נורמה L1: ||x||₁=Σ|xᵢ|; נורמה L2: ||x||₂=√Σxᵢ².
- מרחק אוקלידי בין רשומות: d(x,y)=||x−y||₂.
- נרמול: x/||x|| כאשר x≠0. נרמול לפי L1 ולפי L2 אינם זהים.
- קואורדינטות פולריות (דו־ממד): r=√(x²+y²), θ=atan2(y,x); חזרה x=r cosθ, y=r sinθ.

## מטרות מדידות
1. לחשב ידנית חיבור, חיסור, כפל בסקלר ומכפלה פנימית.
2. לחשב נורמות L1/L2 ולהסביר קשר למרחק.
3. לכתוב את אותן פעולות ב־Python באמצעות for, zip, ביטויי רשימה ו־NumPy.
4. להסביר משמעות גאומטרית ושימוש ב־KNN, מערכות המלצה ודמיון.

- **שימור המקור:** סימן ? הוא מיקום להשלמת פקודת Python או חלק ממנה. אל תחליפו את התרגיל בשאלה מילולית בלבד.
